## C. 예측 비교의 공정성 — 추가 진단

커밋 코드를 import만 해서 같은 시드·origin으로 대안 예측식을 계산했다(새 모델 추가 아님, 해석 점검용, 저장소 밖에서 실행). 기본 조건, p=.45, n=240.

| 예측식 | MAE(t) | 비고 |
|---|---:|---|
| order_3ma (제출 기준) | 49.872 | |
| order_2ma (최근 2개월 O_LC 평균/p) | **33.561** | 묶음 주기와 창 일치 |
| order_6ma | 36.836 | |
| direct (제출) | 32.495 | |
| with_state (제출) | 28.282 | |
| state 단독 | 26.545 | |
| proxy 최근 3개 평균 | 30.260 | |
| **proxy 최근 1개** | **23.271** | 필터·결합 없음 |
| 고정 .25×order_3ma + .75×proxy3 | 29.903 | with_state와 같은 order 가중 |
| 고정 .5×order_2ma + .5×proxy3 | 24.750 | |

order_3ma 오차를 origin 짝/홀로 나누면 평균 **+43.7t / −44.4t**로 진동한다. 3개월 창이 2개월 묶음발주를 1회 또는 2회 포함하기 때문이다.

해석:
1. **기준모델이 구조적으로 불리하다.** 3개월 창과 2개월 묶음의 불일치만으로 MAE가 약 16t 부풀려졌다. 묶음 주기에 맞춘 단순 주문 평균(33.6)은 direct(32.5)와 거의 같다. 따라서 "주문 49.9 → 관측 활용 32.5"의 개선 폭 대부분은 **기준 창 선택의 산물**이다.
2. **with_state의 개선(−4.2t)은 칼만 필터 고유의 우위로 볼 근거가 없다.** with_state에서 order_3ma의 실효 가중은 .5→.25로 줄어든다. 같은 가중의 고정식(29.9)이 with_state(28.3)에 근접한다. 남은 차이는 필터 상태가 가장 최근 대리지표(origin−1)에 더 무게를 두는 **최신성 효과**로 설명된다. 실제로 최근 대리지표 1개(23.3)가 with_state보다 좋다. 과제에서 질문한 "direct는 최근 3개, with_state는 긴 이력"의 차이는 긴 이력 축적보다는 최신 관측 가중으로 작용한다.
3. **공급비중:** 주 조건 p=.45와 원단위 b=2kg/대는 생성기의 참값과 **정확히 같다**. 이는 문서에 숨겨져 있지 않지만(README·IDENTIFIABILITY) 답변에는 드러나지 않는다. p=.60이 기본 조건에서 with_state MAE를 약간 낮춘 것(27.89)은 order 진동 진폭이 1/p로 줄어든 결과로 보이며, 참 비중 추정과는 무관하다. 문서의 "오차 상쇄 가능성" 설명과 일치한다.
4. RESULTS.md·README는 "Kalman 우위 증명 아님, 구조/가중 효과"라고 이미 명시했다(**적절**). 그러나 지원서 답변 2에는 이 단서가 없다 → R3-01.

## D. 불확실성 구간 (포함률 45.0% / 21.7%)

원인(코드·가정 기준):
1. **전이 모형 불일치:** 랜덤워크(Q=36, sd 6t/월)가 계절 진폭 18t, 추세, 평가 구간 안의 수요 충격(+30t, 기간 38–41)을 반영하지 못한다. 충격 영향 origin(37–42)을 제외하면 기본 조건 포함률은 68.3%로 오르지만 여전히 95%에 못 미친다.
2. **주문 관측식 불일치:** 홀수 달 O_LC=0과 짝수 달 약 2배 주문을 모두 `C + N(0,45²)`로 처리한다(111–112행). 실제 편차는 ±C(약 100t) 수준으로 가정 잡음보다 크고, 정규·독립 가정도 맞지 않는다.
3. **대리지표 지연:** 최신 대리지표가 origin−1이므로 실제로는 2스텝 앞 예측이다. 분산식은 이를 반영하지만, 1번의 계절 기울기 때문에 평균이 체계적으로 뒤처진다.
4. **오염 조건:** +50% 체계적 편향은 모형에 없으므로 포함률 붕괴(21.7%)는 예상된 결과다.
(참고: 대리지표 가정 잡음 sd 12t은 생성 잡음 약 7t보다 크다. 즉 이 항목은 구간을 오히려 넓힌다.)

**판단:** 지금 단계에서 보정은 **필수 아님**. 실패 사례로 공개하는 것으로 충분하다. RESULTS.md("NOT calibrated guarantees"), README, 답변 2("실무 확률 보증으로 쓰지 않습니다") 모두 오인 소지가 없다. 단, latest_scenarios.csv의 `state_forecast_low/high` 열에는 경고가 붙어 있지 않다 → R3-06(선택).

## E. 합성 데이터와 누수

- **평가 정답 비투입: 확인.** forecast()는 events만 받는다. truth는 evaluate()에서 예측 후에만 결합되고(137행), 테스트 7이 정답 변조 시 예측 불변을 검증한다.
- **origin 이후 공개 자료: 누수 없음.** 85행 `period<=origin and available_at<=origin`. proxy는 t+1, 재고 보고는 t+2에 이용 가능. 테스트 2가 미래·미입수 값 변조 시 불변을 검증한다.
- **간헐 재고·롯데 출하의 오용: 없음.** 필터는 order_lc와 production_proxy만 사용(103행). 테스트 3이 확인.
- **대리지표 구조의 한계:** `units = C×500 + N(0,3500)` → C 환산 잡음 sd ≈ 7t. 즉 대리지표는 **한 달 늦게 도착하는 거의 직접적인 C 측정값**이고, 필터의 원단위 b=2도 생성값과 같다. 따라서 기본 조건의 "복원"은 대체로 지연된 C 관측을 읽는 일이다. 실제 생산대수→소재 투입 변환에는 BOM 믹스·재공·스크랩이 있어 이처럼 깨끗하지 않다. 문서는 "유리한 관측 가정"이라고 명시했다(적절). 답변에는 반영이 필요하다 → R3-01.

### R3-07 [선택] 답변 분량 활용
