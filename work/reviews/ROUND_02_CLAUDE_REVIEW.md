## 1. 제출 전 필수 수정

### R2-01 [필수] 식별 조건표에 "롯데 관측 집합" 행이 없다 — *논리 누락*
- 위치: IDENTIFIABILITY_REVIEW.md §3 표, RESEARCH_SCOPE_V1.md "관측 조건"
- 문제: 표의 O·I·R·A·L은 모두 **B 내부 자료**(전체 공급사 주문, B 재고, B 입고)다. §2 마지막 문단에서 롯데는 자사 주문 O_LC만 본다고 정확히 지적했지만, 표와 실험 설계에는 반영되지 않았다. 롯데 관점에서 "O만" 조건조차 성립하지 않는다(롯데는 전체 공급사 O를 모른다). 실제 롯데 쪽 관측 후보는 대략 `O_LC(자사 주문) / S_LC(자사 출하) / 고객이 간헐적으로 공유하는 재고·생산계획 / 공개 산업·회사 지표`다.
- 영향: 이 행이 없으면 실험의 "O만 / O+I / I+R+조정"이 누구의 데이터인지 불분명해지고, 심사위원이 "그 데이터는 롯데가 갖고 있지 않다"고 지적할 수 있다. 또 I+R+A+L은 B가 공유하면 회계로 끝나는 문제라 AI 기여가 없다(문서도 이를 인정함).
- 최소 수정: §3 표에 행 하나 추가 — "롯데 관측: O_LC + S_LC (+ 간헐적 고객 재고 보고, + A 생산 대리지표)". 추정 가능한 것: 롯데 공급분의 소비 대응량 범위, 비중 변화 시 식별 불가. 실험의 관측 조건 중 하나를 이 행으로 교체(조건 수를 늘리지 않음).

### R2-02 [필수] "의미 있는 AI 문제"가 아직 수식 수준으로 정의되지 않았다 — *근거 부재*
- 위치: IDENTIFIABILITY_REVIEW.md §6B "AI 활용 후보는 자료 부족/잡음하의 상태 추정이며 방법 선택은 다음 단계"
- 문제: 문서는 (a) 완전 관측이면 회계, (b) O만이면 식별 불가라고 올바르게 결론냈다. 그러면 AI가 의미를 갖는 영역은 그 사이, 즉 **불완전·잡음 관측 + 외부 신호가 C에 대한 추가 측정식을 제공하는 경우**뿐이다. 이 구조가 명시되지 않으면 "식별 불가인데 무엇을 추정하나"라는 질문에 답할 수 없다.
- 최소 수정(새 모델 추가 아님, 정의만): 상태공간 형태로 한 문단 정의.
  - 상태: C_t(소비), I_t(재고)
  - 전이: 수급식 I_t = I_{t-1} + R_t − C_t (+잡음)
  - 측정식: ① O_LC·S_LC (공급비중·리드타임 가정 포함) ② 간헐적 I 보고(결측 허용) ③ A 생산 대리지표 × 원단위(불확실) ≈ C
  - 출력: origin 시점까지의 자료만 쓴 **필터링** 추정치 C_t|t와 구간
  - 식별의 원천은 ③과 ②이며, 둘 다 없으면 구간만 낸다.
  이렇게 쓰면 "AI = 불완전 정보 하의 잠재상태 추정 + 불확실성 정량화"가 분명해지고, 사용자가 설명할 수 있는 최소 방법(칼만 필터 계열 1개)과 바로 연결된다. 방법 확정은 orchestrator 결정(R2-D2).

### R2-03 [필수] 반례의 결론 범위: "규모"까지 식별 불가는 과대 — *논리 오류(부분)*
- 위치: IDENTIFIABILITY_REVIEW.md §3 표 O만 행 "C의 경로·규모와 재고 조정을 유일하게 분리 불가"
- 검산: 반례 자체는 맞다. O=100, I_{t-1}=I_t=20, A=L=0에서 R=100→C=100(ΔW=0), R=40→C=40(ΔW=+60). 같은 O·I, 다른 C. 수급식 `C_t = R_t − ΔI_t + A_t − L_t`, `W_t = W_{t-1} + O_t − R_t` ⇒ `C_t = O_t − ΔW_t − ΔI_t + A_t − L_t` 유도도 정확하다. 구간 예시 R∈[40,100]⇒C∈[40,100]도 맞다.
- 문제: 위 식을 T개월 합하면 `ΣC = ΣO − (W_T−W_0) − (I_T−I_0) + Σ(A−L)`. 재고·미입고 잔량이 유한 범위(용량·정책상 상한)라면 기간이 길수록 **평균 소비 수준은 평균 주문으로 근사 식별**된다. 식별이 안 되는 것은 주로 **월별 타이밍(경로)과 단기 변동의 분해**다. "규모"까지 불가라고 쓰면 사실보다 비관적이고, 반대로 AI 과제의 핵심(단기 분해)이 흐려진다.
- 최소 수정: "단일 월·단기 경로는 식별 불가. 장기 평균 수준은 재고·잔량이 유한하다는 가정하에 주문 평균으로 근사 가능(가정 명시)." 한 줄.

### R2-04 [필수] 예측 대상의 문서 간 불일치 정리 — *일관성 결함*
- 위치: SCOPE_BRIEF.md "예측·사용자"(주문량 `A×B×PC/ABS×요청납기월`) vs RESEARCH_SCOPE_V1 "미래 대상: C의 다음 1~3개월"
- 문제: AGENT_HANDOFF 표에 차이가 기록됐지만 SCOPE_BRIEF는 "이력 보존"일 뿐 무엇이 현행인지 문서 자체에 표시가 없다. 제출 답변 작성 시 두 정의가 섞일 위험이 크다. 또한 롯데 의사결정(생산·재고)은 결국 **자사 주문/출하**가 필요하므로, C 예측만 하고 "롯데 주문 전망은 후속"으로 두면 현업 연결(심사 기준 '비즈니스 임팩트')이 약해진다.
- 최소 수정: RESEARCH_SCOPE_V1에 한 줄 — "1차 산출 = C 예측(구간 포함), 2차 산출 = 가정한 공급비중·재고정책을 적용한 롯데 주문 시나리오(정확도 평가 대상 아님)". SCOPE_BRIEF 상단에 "V1로 대체됨(2026-11-02)" 표기는 Codex 대응 시 처리.

## 4. 사용자 또는 orchestrator 결정 사항

- **R2-D1 연구 방향 채택 여부.** 소비 복원은 "End Customer 수요예측"의 근거(주문은 왜곡된 신호다)로 설득력이 높다. 다만 제출 답변에서는 헤드라인을 "역문제 연구"가 아니라 **"주문 왜곡을 보정하는 End Customer 소비 기반 FCST 체계"**로 두고, 복원은 그 안의 한 층(상태 추정 층)으로 배치할 것을 권고.
- **R2-D2 최소 추정 방법.** 권고: 칼만 필터 계열 1개(필터링만) + 단순 기준모델. 사용자가 원리를 설명할 수 있는 수준. 딥러닝 등 추가 모델은 불필요.
- **R2-D3 시연·에이전트 구현 여부.** 선택지: (a) 답변만 제출, 시연 없음 — 에이전트 완성도 근거 약함 (b) 단일 스크립트 시연 + 규칙 기반 점검(단위·시점·식별 불가 경고)과 LLM 요약 한 단계 (c) 시연 없이 설계 상세화. 일정상 (b)의 최소판 또는 (a) 중 하나를 **11/2 안에** 결정 권고.
- **R2-D4 롯데 주문 시나리오(2차 산출)를 답변에 포함할지** (R2-04).
- **R2-D5 AI 도구 사용 규정 미확인 상태로 제출할지.** RULES_CHECK의 "금지 없음≠허용 확인" 처리는 적절. AI 역량 답변에 사용 도구를 사실대로 기재하는 것이 가장 안전.

## 5. 최종 판정

**수정 후 진행.**

이유: 수학·누수·과장 통제는 진행 가능한 수준이다. 그러나 R2-01·R2-02 없이는 "AI가 무엇을 푸는가"를 심사위원과 사용자 본인이 설명하기 어렵고, R2-04 없이는 답변의 예측 대상이 흔들린다. 네 항목 모두 문서 몇 줄 수준의 수정이며 새 기능·모델을 요구하지 않는다. 범위 재검토까지는 필요 없으나 R2-09의 축소는 일정상 강하게 권고한다.

이 판정은 내부 리뷰 의견이며 주최 측 평가·승인과 무관하다.
