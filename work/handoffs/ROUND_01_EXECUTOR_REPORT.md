## 3. 예측 대상과 연결 논리

최상위 관리 단위는 End Customer A다. 직접 주문처 B는 A 관련 부품을 만드는 성형업체로 가정하고, B가 여러 End Customer를 담당하면 귀속 비율 또는 부품별 납품 매핑을 내부에서 받아야 한다. 같은 소재 주문을 End Customer마다 중복 집계하지 않는다.

1. 공개 산업 생산·판매는 외부 보조 신호. 국가 지표를 사용하려면 지역·품목·고객 생산비중·생산거점 범위가 필요하다. 회사 판매도 생산과 다르므로 재고·수출·거점·모델 구성을 확인해야 한다.
2. A의 거점/차종별 생산계획 × 채택 부품 수 × 해당 소재 투입 kg/부품 ÷ 1,000으로 톤 단위 소요를 계산한다. 순제품 중량으로 시작할 때만 수율·스크랩 회수 가정을 추가한다. 원단위에 손실이 이미 포함됐다면 중복 가산하지 않는다.
3. B의 총 조달 필요는 소비 + 목표 기말 재고 − 기초 재고 − 이미 도착 예정인 입고를 바탕으로 계산하고 부족량을 0 이상으로 제한한다. 롯데 배분율·다른 공급사 입고·최소주문량을 일관되게 반영하고, 공급 비중을 재고 조정 전후에 중복 적용하지 않는다.
4. 요청납기와 리드타임에 따라 발주 시점을 따로 관리한다. 확정 미입고 주문은 총 필요에 포함된 부분을 표시해 추가 발주와 중복 합산하지 않는다.

이는 설명용 수급 구조다. 실제 구매 방식·소재 대체·유통 경로에 맞춰 현업 검토가 필요하다. 소비량과 주문량, 발주월과 납기월, 주문량과 출하량은 별도 필드로 둔다. **공개 대수×임의 상수만으로 실제 고객 주문을 예측했다고 쓰지 않는다.**

## 4. 다음 단계 작은 시연의 입출력 계약 — 이번에는 설계만

입력 3묶음:

- 모델이 수치를 계산하고 에이전트는 점검·실행 연결·근거 설명·확인 요청을 담당한다. 규칙 기반으로만 구현한다면 그렇게 표시하고 LLM 에이전트는 설계로 남긴다.

검증 기준:

1. 스키마·월 중복·kg/톤·대/지수 혼동·음수 주문·누락·0주문·공급비중 범위·공급사 중복을 검사. 고의 오류 입력을 잡거나 설명과 함께 중단하면 통과.
2. `available_at <= forecast_origin`과 판본 기준을 확인한다. 미래 공표 자료를 넣은 테스트는 거부/제외되어야 한다. 오늘 읽은 수정치를 당시 값으로 사용하지 않는다.
3. 합성 36개월 중 28~33번째 월말을 origin으로 두고 각 1~3개월 앞을 순차 평가한다. origin별 재학습·전처리를 과거에만 맞춘다. 기준은 최근 3개월 평균. 비교 방법 하나는 데이터 형태를 보고 다음 단계에 선택한다. 외부 변수의 미래 실제값은 금지하고 당시 계획/가정만 사용한다.
4. horizon별 MAE(톤), WAPE=오차 절댓값 합/실제 합, 편향=예측−실제 평균을 보고한다. 실제 합이 0이면 WAPE는 N/A, MAE 유지. 합성 자료의 개선율을 실제 효용으로 표현하지 않는다.
5. 수급 식과 단위가 손계산 예시와 맞는지, 가정을 바꾼 결과를 재현할 수 있는지, 동일 입력에 동일 결과인지 확인한다. 비교 모델이 기준보다 좋아야 동작 검증 통과라는 조건은 두지 않는다.
