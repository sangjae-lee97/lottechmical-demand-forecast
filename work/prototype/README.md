# 최소 합성 FCST 실행 안내 — Round 03

**실제 고객 성능의 증거가 아닌 합성 메커니즘 실험이다.** Python 3.12 표준 라이브러리만 사용하며 패키지 설치·API 키·외부 LLM·웹 UI가 없다. 프로젝트 루트에서 실행:

```powershell
python work/prototype/experiment.py
python -m unittest discover -s work/prototype -p test_experiment.py -v
```

기본 실행은 20개 시드, 각 48개월, 기본/대리지표 오염 두 조건, 공급비중 가정 .30/.45/.60을 계산한다. 같은 이름의 `results/` 산출물을 재생성한다. 다른 폴더에 기록하려면:

```powershell
python work/prototype/experiment.py --out work/prototype/results_check
```

## 사용자가 설명할 핵심

‘롯데가 보는 주문은 B의 전체 소비가 아니다. 주문과 늦게 들어온 생산 대리지표를 신뢰도에 따라 섞어 현재 소비를 추정하고 다음 달을 예측한다. 입고가 빠진 재고는 소비 측정값으로 쓰지 않는다. 추정이 오히려 나빠질 수도 있어 담당자에게 가정·불확실성을 확인시킨다.’

## 자료 경계와 생성 가정

가상 완성차 A–가상 성형업체 B, PC/ABS 한 소재군. B의 모든 생산이 A에 귀속된다고 가정한다. 실제 고객관계·BOM·공급비중의 근거가 아니다. 전체 소비 C·전체 주문 O·전체 입고 R·재고 I·미입고 W는 생성기 내부에만 있고, 롯데 관측 O_LC/S_LC와 분리했다.

- C는 100톤 수준+월별 계절성+완만한 추세+잡음+기간38~41 수요 충격. 재고가 부족하면 실제 소비는 가용 재고로 제한한다. 희망 소비와 실제 소비는 별도 열이다.
- 기초 재고 400톤. 고객은 매 2개월마다 최근 소비·재고·미입고를 보고 주문하며 2개월 뒤 입고된다. 자사 공급비중은 생성 조건 .45, 자사 출하는 입고 1개월 전으로 설정한다. M(반품/이동)·L(창고 손실)=0.
- 대리지표는 C를 가정 원단위 2kg/대로 환산한 값에 잡음을 더한다. 실제 생산대수와 소재 불출의 간극을 단순화한 **유리한 관측 가정**이다. 실제 공개 자동차 생산/판매 표를 시연에 투입하지 않았다.
- O_LC는 월말 즉시 이용 가능. S_LC·대리지표는 대상월+1, 분기별 I 보고는 대상월+2에 이용 가능하다. 실제 고객 보고 접근·지연을 확인한 값이 아니다.
- 오염 조건은 기간30 이후 대리지표만 50% 높인다. 기본 조건과 실제 C·O·R·I는 같다. 의도적인 실패 조건이다.

## 칼만 필터 1개와 세 예측

상태: C_t. 전이 `C_t=C_(t-1)+w`, 과정 분산 Q=36. 초기 평균100·분산2500. 독립 가우시안 잡음은 단순 가정이다. 계절·묶음발주·체계적 대리 오염은 모형 가정에 맞지 않을 수 있어 최적 추정 보장은 없다.

측정: `O_LC/p=C+v_o`(표준편차45톤), `proxy×2/1000=C+v_p`(표준편차12톤). 실제 입고 없는 I 및 S_LC는 측정식에서 제외한다. 발주/재고 왜곡은 첫 측정의 큰 잡음에 근사되며 원인별로 분리 식별하지 않는다. p·원단위·Q·잡음·결합 가중치는 실행 전 고정, 숨은 C나 마지막 평가 구간으로 튜닝하지 않는다. 주 가정 p=.45와 참 공급비중이 같은 조건 및 틀린 조건 .30/.60을 모두 공개한다.

매 origin에서 `period<=origin` 그리고 `available_at<=origin`인 관측만 추린다. 지연 보고가 속한 과거 대상월에 측정식을 적용해 origin까지 순방향으로 재실행하고 **현재 상태만** 추출한다. 지연된 과거 보고를 현재월 소비라고 붙이지 않는다. 과거 평가 origin에서 알 수 없던 보고를 사후 추가하지 않는다.

1. `order_3ma`: 최근3개월 O_LC 평균/p. 같은 미래 C를 비교하기 위해 공급비중 가정을 쓰는 주문 단독 기준이다.
2. `direct`: (1)과 당시 이용 가능한 최근3개 proxy 환산 평균의 고정 50:50 결합.
3. `with_state`: (2)와 현재 필터 상태의 고정 50:50 결합. 다음 달은 랜덤워크의 현재 평균으로 예측한다.

두 결합은 추가 학습 모델이 아닌 고정 예측식이다. (2)(3)은 동일 관측을 사용하므로 (3)에는 새 정보가 없고 시간 구조·가중의 효과만 평가한다. 실제 소비 C는 `forecast`의 인자/필드에 없으며 생성·사후 평가에서만 사용한다. B 전체 R/I/O와 참 공급비중도 필터에 제공하지 않는다.

최근3개월 안 대리지표가 없으면 `NOT_IDENTIFIED`: 상태 평균·구간·결합 예측을 비운다. 주문 기준은 가정별 참고 시나리오일 뿐 소비 복원값이 아니다. 충분한 보조 정보 없이 임의로 좁은 범위를 출력하지 않는다.

## 출력과 검증

`results/RESULTS.md`: 주요 MAE·편향·시드별 MAE 범위·최악 사례·담당자 확인 요청. `metrics.csv` 전체 조건, `predictions.csv` 4,320행, `latest_scenarios.csv` 마지막 시점 추정·경고·조건부 구간·롯데 주문 시나리오, `order_only_status.json` 식별 불가 예시. `*_observations.csv`는 시드0 관측, `*_truth_EVALUATION_ONLY.csv`는 시드0 생성 진실(수급 감사/평가 전용), `assumptions.json`은 고정 가정이다. 기간은 실제 달력 대신 0~47 월 인덱스다.

평가 origin35~46에서 target36~47, 각 시드 마지막12개월·한 달 앞. MAE와 편향(예측−실제), 현재 상태 MAE 및 상태 단독 다음달 구간 포함률을 사후 평가한다. 겹친 시점이 있어 240개 예측이 독립 표본은 아니다. 모델을 결과에 맞춰 다시 고르거나 잡음을 재조정하지 않았다.

기본 p=.45 MAE: 49.872/32.495/28.282톤. 오염 조건: 49.872/42.127/47.447톤. 상태 추가가 직접 활용 대비 기본은 개선(-4.213), 오염은 악화(+5.320)했다. 명목95% **상태 단독** 가우시안 구간의 실제 포함률은 45.0%/21.7%로 낮다. 이 구간은 결합 예측의 구간이 아니며 공급비중·BOM의 체계적 불확실성도 제외한다. 표시하되 확률적 신뢰 보증으로 사용하지 않는다. 공급비중별 시나리오는 별도 비교한다.

`innovation_flags`는 관측 잔차가 모형상 표준편차2.5배를 넘은 횟수다. 오류 원인을 자동 확정하지 않는다. 최종 출력은 원단위·귀속·공급비중·보고 지연·대리지표 오염을 담당자가 확인하도록 요청한다. 롯데 주문 시나리오는 재고 일정·미입고 조정 없음 가정에서 p×소비 전망으로만 제시한다. 발주 시점·실제 주문 정확도는 평가하지 않는다.

7개 테스트는 수급 보존·자사 부분집합, 미래/미입수 이벤트 변조 불변성, 입고 없는 재고·자사 출하 비사용, 주문만 있을 때 기권·공급비중 영향, 단위/중복/이용시점 오류 거부, 시드 재현과 오염 시 실제 수요 불변, 평가 정답만 바꿔도 예측은 변하지 않음을 확인한다. 모형 수식 자체를 맞는 결과로 외우는 테스트가 아니다.

## 구현 범위와 남은 일

규칙 기반 CLI 흐름이다. 칼만 필터는 LLM/자율 에이전트가 아니다. 실시간 현업 입력·외부 API·대시보드·LLM·자동 발주·추가 모델·3개월 예측은 없다. 참 소비·발주 정책과 proxy의 관계가 실제보다 단순하므로 합성 결과를 실제 예측 역량이나 효과로 일반화하지 않는다. 실제 적용 전 고객 데이터 권한·BOM·관측 시점 확인, 구간 보정·구조 오식별 검증과 독립 리뷰가 필요하다.
