# ROUND 08-A — 기준월·origin·판본 계약

확인일: 2026-11-03 KST. **실제 실행 상태: 탐색 분석 완료 / NO_VERIFIED_BACKTEST.** 공식 원자료 확보 내역은 `ROUND_08_PRODUCTION_FEASIBILITY.md` 참조.

## 필드와 시간 계약

| 필드 | 의미·이번 처리 |
|---|---|
| `forecast_target_month=t` | BSI가 전망한 달. ECOS TIME의 2026-10·11을 공식 PDF와 앞선 ROUND 07-C에서 대조한 정의를 유지 |
| `survey_month` | `t-1`. 생산 t와 조인할 키가 아님 |
| `production_period` | 실제 생산지수 대상월. BSI `forecast_target_month`와 정확히 같은 `YYYY-MM`로 조인 |
| `origin` | 목표월 t의 1일 00:00 KST. 이번에는 예측을 실행한 시각이 아니라 가용성 검사를 위한 계약 필드 |
| `publication_date` | 해당 자료 판본의 공식 공표일. 표의 현재 갱신일·파일 생성일로 대체하지 않음 |
| `available_at` | 이용 채널에서 사용 가능한 시각. 날짜만 검증되고 시간은 불명인 경우 다음날 00:00 KST를 보수적 정책으로 적용. 날짜 자체가 미확인이면 null |
| `vintage_verified_for_origin` | 입력한 수치가 해당 origin 당시 이용 가능했던 판본임을 증거와 함께 확인했는가. 이번 현재 스냅샷은 false |
| `asof_evidence` | 원 공표 자료 등 시점·판본 증거 식별자. 단순 최근 조회 URL만으로 충족하지 않음 |

## 정렬 결과와 금지하는 입력

- 생산 57개월(2022-01~2026-09), 자동차 BSI 36개월(2023-12~2026-11), 실제 공통월 **34개월(2023-12~2026-09)**. 연속성과 중복 검사를 통과했다. 없는 2026-10·11 Y는 만들지 않았다.
- 기준선 후보는 생산 `t-12`. 그 값도 실제 가용 판본 검사 대상이다. 생산 `t-1`이 origin 전에 발표됐다고 자동 가정하지 않는다.
- 같은 달 생산 Y_t는 탐색 상관의 비교 대상·향후 평가 정답이며 **예측 입력이 아니다**. 이번에는 학습·예측 호출 자체가 없다.
- BSI의 공표일 확인 구간은 2026-10·11 대상월뿐인데 두 달 모두 Y가 없다. 실제 정렬된 34개월에서는 개별 공표일이 미확인이다.
- 생산지수의 현재 전체 갱신일 2026-10-30은 월별 최초 발표 시점의 대체값이 아니다. 연간보정으로 과거 수치도 변할 수 있으므로 t-12라는 이유로 판본 검사를 면제하지 않는다.

## 차단 로직과 테스트

`analyze_round08.py`의 `verified_input`은 ① 공식 공표일, ② 시간대가 있는 available_at, ③ 판본 확인 true, ④ 시점·판본 증거가 모두 있어야 통과시킨다. available_at은 공표일보다 빠르지 않고 origin 이하여야 한다. 하나라도 없거나 모순이면 false다. 다운로드 시각이나 추정 발표일로 null을 채우지 않는다.

실제 데이터에서 BSI와 계절 기준선이 함께 통과한 origin은 **0개**다. 실행 결과에 `NO_VERIFIED_BACKTEST`를 출력하고 모델 비교를 수행하지 않는다. 코드에는 학습·예측 경로를 넣지 않았으며, 향후 증거를 갖춘 뒤 별도 검토를 거쳐 추가해야 한다. 이 플래그는 사람이 붙인 증거의 진실성까지 자동 입증하는 기능이 아니다.

`test_round08.py`는 공식 수치를 포함하지 않은 합성 fixture로 실행한다. 5개 테스트에 포함된 핵심 검사는 다음과 같다.

1. 월 중복·누락은 실패, 정상 연도 경계는 통과.
2. 조사월의 다른 생산값을 준비해도 목표월 Y를 정확히 선택. 없는 미래 Y 제외.
3. 미래 available_at·날짜 누락·시간대 누락·판본 false·증거 누락·공표일보다 빠른 이용일은 차단.
4. 잘못된 T20 항목 DSD를 T10 생산 원지수로 받아들이지 않음.
5. 소표본·상수계열에서는 상관 미산출, 알려진 합성 상관은 검산.

## 탐색과 예측평가의 구분

현재 실행한 것은 **최신 ECOS/KOSIS 스냅샷의 소급 탐색**이다. 원지수와 전년동월비의 Pearson 상관 및 사전 지정 k=-1,0,+1 비교를 산출했다. k는 생산 상대월이므로 +1이 BSI 조사월보다 한 달이라는 뜻이 아니다. 고정된 동일월 공통기간을 BSI anchor로 삼고 대응 생산이 없으면 제외하여 +1의 n만 33이다. 시차를 최적화하거나 최고 상관을 모델 선택에 쓰지 않았다.

후속 엄격 평가에는 당시 이용 가능했던 BSI·생산 판본과 실제 공표 기록이 필요하다. 같은 origin·target·학습 구간·기준선 정보에 BSI만 더해 비교하고, 변환·정규화·추정은 과거 학습 구간에서만 해야 한다. 현재 상관을 MAE 개선이나 선행성 증거로 대신하지 않는다.

BSI 2026-11부터 표본개편·KSIC-11 단절 후보를 유지한다. 생산 표의 KSIC-10 주석과 차이를 확인했다. 현재 공통기간에는 개편 후 BSI가 없어 개편 전후 비교는 불가능하다. 산업 생산과 고객별 PC/ABS 소비의 연결도 별도 미검증이다.
