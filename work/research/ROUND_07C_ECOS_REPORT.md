# ROUND 07-C — 정식 ECOS 인증키 기반 시계열 확보·품질 검증

확인일: 2026-11-03 KST / 수행: Codex / 범위: 공식 공개 집계 시계열 수집 및 오프라인 검사. 모델·Agent 구현과 학습은 하지 않았다.

**결론: 정식 인증·조회 성공. 자동차와 제조업 전체 신규수주 전망 BSI를 각각 36개월, 총 72행 확보했다. 외부 산업지표 입력 후보로 채택할 근거는 확보했으나, 역사적 공표일·판본과 표본개편 처리가 미완료이므로 전체 기간의 시점 준수 백테스트 입력으로 바로 사용하지 않는다.**

## 2. 값·월·단위 검증

- 두 업종 모두 기대 월 목록과 API `TIME` 목록이 완전히 일치했다. **누락 0, 중복 0, 비수치·비유한 값 0, 지수 허용범위 0~200 밖 값 0**. 보간·결측 대체·중복 제거로 수를 맞추지 않았다.
- 응답 `UNIT_NAME`은 **72행 모두 null**이었다. 원본 null을 보존하고, 한국은행 조사 개요의 BSI 정의에 근거한 별도 `semantic_unit=index`를 기록했다. API가 단위를 명시해 반환했다고 쓰지 않는다.
- BSI는 긍정 응답 비중−부정 응답 비중+100의 지수다. 신규수주 질문의 비교 기준은 **전년 동월 대비 방향**이다. 지수 1p를 물량 1%로 바꾸거나, 100 초과를 전월 대비 물량 증가로 해석하지 않는다.
- 아래 4개 값은 앞선 ROUND 07에서 공식 PDF 표를 실제 확인한 전사 표본과 재대조해 모두 일치했다. 이 대조로 최근 두 달의 `TIME`이 **전망 대상월**임을 확인했다. 나머지 월도 동일 항목의 월 인코딩을 적용했지만, 36개월 전부를 원 공표 PDF와 개별 대조한 것은 아니다.

## 3. 공표·이용 시점과 수정 판본의 미확인 범위

`StatisticSearch`의 실제 관측 행에는 월·값·항목·단위 등이 있으나 개별 공표일·최초 수록 시각·수정일·판본 필드는 없었다. 이번에 받은 값은 **2026-11-03 현재 API 스냅샷**이며 최초 발표 당시 값이라고 단정하지 않는다.

- 두 전망월 × 두 업종의 4행은 공식 게시일을 확인했다. **나머지 34개월 × 두 업종 = 68행은 공표일과 이용 가능 시점을 null로 보존**했다. 월말·평균 시차를 이용해 임의 생성하지 않았다.
- 72행 전체의 수정 이력·최초 발표 판본은 미확인이다. 최신값이 당시에도 같았다는 보장이 없으므로 최종 수정값을 과거 예측 입력으로 소급하지 않는다.
- 10월 PDF 파일명 `_vF`는 확보한 첨부 판본 식별자일 뿐, 정정 발생·정정일·수정 수치 전체를 확인했다는 증거가 아니다.
- 원본별 SHA-256과 로컬 파일 저장 시각(UTC)을 manifest에 기록했다. 파일 저장 시각은 공식 공표 시각이 아니다.

다음 단계에서 공식 과거 보도자료/일정과 기준월을 연결하고, 원 발표 값 또는 당시 이용 가능했던 판본을 확인해야 한다. 미확인 행은 시점 기반 평가 입력에서 제외하거나 보류한다. 이번 작업에서는 추가 역사 자료의 대규모 수집·모델 입력을 하지 않았다.

## 4. 2026년 10월 표본개편·KSIC-11

10월 공식 PDF ‘알리는 말씀’(물리 2쪽)은 모집단 기준 2021년→2024년, 표본 수 3,524→3,639개, KSIC-11 반영 및 10월 조사부터 새 표본을 안내한다. 개편 전후 비교에는 표본 변화 영향이 포함될 수 있다.

**조사월 경계는 2026-10, 이번 전망 대상월 계열의 경계는 2026-11이다.** 10월 보고서의 10월 전망은 이전 조사 값이고 11월 전망부터 새 표본이다. 정규화 자료에 2026-11 단절 가능성 플래그를 넣었다. 현재 새 표본 관측은 업종별 1개월뿐이므로 연결계수·개편 효과를 추정하지 않았다. 단절을 실제 수요 급변이나 주문 왜곡의 원인으로 해석하지 않는다. 앞선 35개월에 다른 방법 변경이 전혀 없었다는 보증도 하지 않는다.

## 5. 이후 입력 후보 판단

**조건부 후보 유지**: 자동차 업종의 다음 달 신규수주 기대는 생산·수출의 과거 실적과 정보 성격이 다르므로 추가 정보를 줄 가능성은 있다. 제조업 전체도 비교 후보로 확보했다. 다만 같은 경기·수출 환경에 반응하므로 생산·수출 및 두 BSI 사이 중복 가능성이 있고, 선행성·추가 예측력은 미검증이다.

후속 평가 조건은 ① 공표·판본 기준의 시점 정렬, ② 표본개편 전후 구분, ③ 기존 입력만 쓴 기준모델 대비 추가 가치 확인이다. 공개 산업지표와 롯데 주문의 차이는 **괴리 탐지 및 담당자 확인**의 후보로만 다룬다. 고객별 PC/ABS 실제 소비량, 공급비중, 채찍 효과의 원인을 복원한 근거가 아니다. 고객별 정답이 없으므로 실제 고객 예측 성능을 주장할 수 없다.

## 6. 보관·재현·보안

- 수동 수집 도구: `work/research/collect_round07c_ecos.py`. 인증키는 `.env`에서만 읽고 요청 URL·키를 출력하지 않는다. 응답에 키가 포함되면 저장을 차단하며 전송 예외의 상세 URL도 출력하지 않는다.
- 오프라인 검증: `work/research/verify_round07c_ecos.py`. 현재 검증은 이번 2페이지 응답과 이전 ROUND 07의 로컬 PDF 확인 표본을 전제로 한다. 모델·Agent가 아니다.
- 로컬 전용 폴더: `work/data/local_only/round07c_ecos/`. 목록·항목·조회 응답, `normalized_snapshot.json`, `validation.json`, `manifest.json`을 저장했다. 원본과 정규화 자료 모두 Git 제외 대상이다. 이전 PDF/전사 표본도 로컬 전용이다.
- `.env`는 Git에서 제외되고 추적되지 않음을 확인했다. 생성 JSON 및 이번 코드·보고서의 실제 키 문자열 검사는 노출 없음으로 확인했다. 인증키가 들어간 요청 URL을 보고서에 기록하지 않았다.
- [공공데이터포털 한국은행 기업경기조사](https://www.data.go.kr/data/15059630/openapi.do)는 이용허락범위 제한 없음으로 표시하지만, 이번 ECOS 응답과 PDF 각각에 적용되는 재배포 조건을 완전히 확인한 것으로 확대하지 않는다. **원본·정규화 데이터 모두 공개 GitHub에 업로드하지 않았다.**

PowerShell 재현 명령(키 값을 명령줄에 넣지 않는다):

```powershell
python -X utf8 work/research/collect_round07c_ecos.py tables
python -X utf8 work/research/collect_round07c_ecos.py items 512Y008
$env:ECOS_PAGE_SIZE = '20'
python -X utf8 work/research/collect_round07c_ecos.py search 512Y008 M 202312 202611 BD C3000
python -X utf8 work/research/collect_round07c_ecos.py search 512Y008 M 202312 202611 BD C0000
Remove-Item Env:ECOS_PAGE_SIZE
python -X utf8 work/research/verify_round07c_ecos.py
```

키 미설정 시에는 API 키를 대화에 전달하지 말고 로컬 `.env`에 `ECOS_API_KEY=발급받은값` 형태로 저장한다. 조회를 다시 실행하면 당시 최신 스냅샷으로 덮어쓰므로 이번 판본을 유지하려면 로컬 전용 폴더를 먼저 별도 보관한다.

기존 V1 모델·테스트·실험 결과 및 제출 답변 3개는 수정하지 않았다. 추가 학습·예측 실험·Agent 구현은 수행하지 않았다. 후속 사용자 지시에 따라 조사 보고서와 수집·검증 코드만 GitHub에 공유하며, 인증키와 로컬 원본·정규화 데이터는 제외한다.
