# ROUND 08 — 자동차 생산 실측과 신규수주 전망 BSI의 예측가치 검증

작성: 2026-11-03 / 연구 방향: V2 실측 확장
**상태: 아직 모델 성능 결과 없음. 외부 Y 생산지수 확보 및 원본/시점 검증이 우선.**

## 1. 확인하려는 질문

자동차 업종 **신규수주 전망 BSI**는 예측 시점 전에 확보 가능한 기존 생산활동 자료만 사용하는 기준선보다 **다음 달에 실현되는 자동차 업종 생산지수**를 더 잘 설명할 수 있는가?

- X: 한국은행 ECOS `512Y008 / BD / C3000` 자동차 업종 신규수주 **전망** BSI. 보조 비교 `C0000` 제조업 전체.
- Y: 국가데이터처·KOSIS 광업제조업동향조사 `시도/산업별 광공업생산지수(2020=100)`의 **전국 · 자동차 및 트레일러 제조업 · 생산지수(원지수)**. 실제 통계표의 항목/분류 ID와 수치 조회 가능 여부는 **미검증**이므로 자료를 받을 때 검증해야 함.
- 예측 대상과 BSI의 `forecast_target_month`를 `YYYY-MM`으로 맞춘다. BSI 2026-11 값은 **2026-10 조사**에서 발표된 다음달 전망으로서 해당 월 생산지수의 관측치가 아님.
- Y의 원지수(2020=100)는 생산량(대)이나 소재 투입량(톤)이 아니다. Y의 현재 분류가 자동차 부품 등까지 포함하는지 확인하며 **KAMA 완성차 생산대수와 동일시하지 않는다**.
- 고객별 실제 PC/ABS 소비 C나 롯데 자사 주문 O_LC의 예측 성능, 채찍 효과 원인·크기 복원은 이번 실험 범위 밖.

## 3. 이번 실행 범위 (Codex ROUND 08-A)

### A — Y의 실제 공식 원자료 확보·검증

1. KOSIS 통계검색에서 '시도/산업별 광공업생산지수(2020=100)'을 열고 **전국**, **자동차 및 트레일러 제조업**, **생산지수 원지수**, **월별**을 실제로 선택할 수 있는지 확인한다. 통계표 `orgId`, `tblId`, 분류 `objL*`, 항목 `itmId`, 기준년도·단위를 원본 화면/메타데이터로 검증한다. 검색 결과의 잠정 코드(제삼자 예시 포함)를 사실로 단정하지 않는다.
2. 가능하면 2022-01~2026-09 (최소 2023-01~2026-09)의 연속 기간을 공식 Excel 또는 정식 KOSIS API로 확보한다. KOSIS 키는 ECOS 키와 다르며, 신규 키가 필요하면 인증 요구 상태만 보고한다. 계정 제한 우회·무단 재배포 금지.
3. 원본 URL·해시·집계 범위·원지수 여부·기준월·공표/다운로드 시점·수정 정책을 기록한다. 미래 2026-10·11 실제 Y가 없는 경우 결측으로 둔다.
4. 실제 데이터(원본·정규화·수집 응답)는 `work/data/local_only/round08_production/`에 저장한다. 상위 로컬 디렉터리는 루트 `.gitignore`에서 제외됐음. 키·로컬 원자료를 Push하지 않는다.

### B — 시점 정렬 및 평가가능성 우선 검사

1. BSI의 `forecast_target_month`와 Y의 `period`를 매칭하며, BSI `survey_month`를 Y의 같은 달 생산실적으로 잘못 조인하지 않는다.
2. 모든 자료의 기준월, 원자료 게시일, 최초 이용 가능일, 현재 스냅샷과 최초/수정 판본을 분리한다. 공표 시각 불명은 보수적으로 **다음날 00:00 KST**부터 사용하며, 과거 시점의 빈 날짜를 발표 추정치로 채우지 않는다.
3. **정보집합 예측 기준시점:** 목표월 `t`의 1일 00:00 KST. 실제 예측에서는 해당 시점 전에 공개된 BSI 전망 `t`과 과거 생산지수만 입력으로 사용할 수 있다. 생산지수 `t-1`은 아직 게시되지 않았을 수 있으므로 반드시 `available_at` 검사하고, 기본 기준선 후보는 사용 가능한 `t-12` 동일 월 생산지수(계절 기준선)로 한다.
4. 업종/단위·표본/산업분류 개편 전후 호환 여부를 먼저 점검한다. 수록값이 후일 수정된 최신값일 수 있기에 당시 공개판과 현재판이 같은지 확인되지 않는 구간은 **엄격한 과거 백테스트 '미검증'**으로 분류한다.

### C — 탐색적 분석과 검증실험을 분리

- **1차(실행 가능하면):** 같은 대상월의 BSI와 원지수·전년동월비 방향 간 단순 시차 상관, 결측, 2026-11 경계, 분포 등 탐색. `현재 ECOS/KOSIS 조회 스냅샷을 소급 이용한 탐색 결과`로 명시하고 **선행성·예측성능 입증으로 표현하지 않는다**. 연속 월/동일 지표 정합성과 표본수를 명시한다.
- **2차(자료가 준비됐을 때만):** 시점별 실제 가용 판본을 갖춘 월말 또는 목표월 초의 원점(origin) 기준 **rolling/expanding forecast**. 최소 두 비교:
  - baseline: 평가 시점에 이미 공표된 해당 월의 전년동월 생산지수 등 단순 계절 기준.
  - +BSI: **동일한 baseline 정보집합에 BSI만 추가**한 작은 회귀/정규화 모형. 지표 변환·파라미터 선택·정규화는 해당 시점 이전 학습 기간에서만 수행.
  - 비교 가능한 동일 origin·target에 대해 MAE, 편향, 표본수, 방향 정확도(정의 후), 이전/이후 표본개편 구분을 보고. 긴 기간의 동일 '원점' 자료 없으면 점수 산출을 보류한다.
- 자기회귀/미래정보 혼동 방지: `t`의 실현 Y를 `t` 입력으로 사용하지 않는다. `t` 생산지수를 예측한 뒤 이미 발표된 실적을 정답으로만 비교한다. BSI를 목표 `t` 이전 실제 공개 여부 확인 없이 피처로 넣지 않는다.
- 제조업 전체 BSI와 자동차 BSI를 동시에 모두 넣지 말고 **자동차 BSI 한 개만 먼저** 비교. 추가 지표는 정보가 추가되는지 확인한 뒤 도입.
