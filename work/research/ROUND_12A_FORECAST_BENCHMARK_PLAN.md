## 1. 이번 연구 질문 (결과 확인 전 확정)

> "실측 C303 자동차 신품 부품 생산과 C222 플라스틱 제품 생산의 YoY를 예측할 때, 동업종/제조업 신규수주 전망 BSI가 단순 기준선보다 **실질적으로** 예측 오차를 줄이는가? 그 효과가 두 업종, 두 잠정월 제외, 극단월에 대해 얼마나 안정적인가?"

대상:
- Y1 `C303` KOSIS `101/DT_1F02001 / A=00 / B=C303 / T10`: 자동차 신품 부품 생산지수 YoY
  - X1 `512Y008/BD/C3000`: 자동차 신규수주 전망 BSI, `forecast_target_month`로 결합.
- Y2 `C222` 같은 KOSIS 표의 플라스틱 제품 제조업 생산지수 YoY
  - X2 `512Y008/BD/C0000`: 제조업 전체 신규수주 전망 BSI (**플라스틱 전용 BSI가 아님**).
- 두 매핑과 평가 기간은 결과 확인 전에 사전 고정. 결과에 맞는 BSI 교차매핑, lag 탐색, 예측기간 재선택, 모델 튜닝 금지.

입력: 기존 로컬 `work/data/local_only/round09_industry/`의 공식 SDMX/DSD·정규화·해시 및 `round07c_ecos/normalized_snapshot.json`(기존 공식 ECOS 로컬 값). 가능하면 출처 원본 해시 확인 뒤 읽고, 해시 불일치 시 fail closed. 신규 API 호출 불필요. 과거판본 최초공표일 미확인 유지.

## 2. 공정한 고정 실험

- 타깃 `g_t = 100 × (P_t/P_(t-12) − 1)`, 단위 **% YoY**.
- **12개월 평가월 고정**: `2025-10 .. 2026-09`. C30 ROUND 08-B와 같은 월.
- 각 t의 **학습 마감 target month `t-2` 이하**. 초기 2023-12~2025-08(21행), 마지막 2023-12~2026-07(32행). 두 예측모형 동일 공통 패널 학습행/마감. 최소 12행.
- BSI `forecast_target_month=t`를 X_t로 사용; survey month=t-1을 목표 Y의 월로 오조인 금지.
- **주 비교 대상 3모델**, 업종별 같은 정의:
  1. `seasonal_naive`: 예측 YoY=0.
  2. `past_yoy_mean`: 공통 학습월의 YoY 평균.
  3. `bsi_ols`: 같은 학습월에서 절편 포함 단변량 OLS `g=a+b*BSI`; 목표월의 BSI를 대입.
- **부가 벤치마크**: `yoy_last_available_tminus2` = 관측가능하다고 임시 가정한 `g_(t-2)` 값을 그대로 사용. 데이터 발표시점/당시판본이 검증되지 않았으므로 현실 선행입력 보장은 없고 **hindsight 참고 기준선**으로만 취급. 이 부가 모델 도입으로 기존 08-B 주 비교 결과를 바꾸지 않음.
- OLS 기울기/절편, 평균, t-2 목표 시점, 학습행은 평가월 결과를 보지 않고 계산. 사후 잔차에 맞춘 winsorize, clipping, cross-mapping, 최적 시차 탐색 금지.
- 정식 실시간 backtest 아님: 실험 이름 `HINDSIGHT_CURRENT_VINTAGE_EXPLORATORY`, 시점 엄격검증 상태 `NO_VERIFIED_BACKTEST`. `t-2`는 운영 지연 가정이지 최초 발표일 증명이 아님.

## 3. 수치 결과 (각 Y에 대해 반드시 공개 집계)

1. 각 모델 MAE(p.p.), RMSE(p.p.), 평균 편향(predicted−actual, p.p.), n=12, 2025-10~2026-09 고정 결과.
2. 주 비교 BSI vs `past_yoy_mean`, 그리고 BSI vs `seasonal_naive`: `ΔMAE = MAE_BSI−MAE_baseline` (양수=악화), `skill=100×(MAE_baseline−MAE_BSI)/MAE_baseline` (양수=개선). 기준선이 0이면 백분율 생략.
3. 2026-08/09 잠정 월을 제외한 **같은 예측의 10개월** 민감도(새 학습/수정 없음), 집계만 비교.
4. 평가월별 합성/비공개 실측 예측 및 오차를 **로컬 JSON에만** 저장. 공개 보고서에는 가능하면 **각 월의 누가 더 나았는지 건수와 오차차 절대 최댓값, 최악 월 이름 정도의 파생 정보만** 기재. 원본 값/개별 목표 월 실측·예측 숫자 및 원 API 응답은 공개 GitHub 금지.
5. **paired wins** (BSI 절대오차가 평균 baseline보다 작은 월 개수/동률 수/악화 수)와 **leave-one-evaluation-month-out**으로 12번 각각 한 달 제외 시 `ΔMAE`의 최솟값·최댓값 및 개선/악화 방향 전환 여부를 산출. 이것은 강건성 진단이며 사후 평가집합 변경·확증 성능으로 쓰지 않음.
6. 방향 적중(전년동월비 부호 맞춤)은 **부가 지표**로 BSI와 평균에만 제공(0 YoY일 때 분모/점수 정책을 명시). 방향 적중률을 수요예측 정확도로 포장하지 말 것.
7. 타깃별 성능 차이 비교는 정답 변동성, 기저효과, 구간 변화 영향과 구분해 서술. **C222/C303간 단순 절대 MAE가 낮다고 소재 예측이 더 정확하다고 결론 금지.** 12개 월에 대한 통계적 유의성/장기 일반화 주장 금지.
8. `C30` ROUND 08-B 원 지표 성능을 **동일월 참고 표**로 옆에 병기하되, 이전 결과를 재작성/원본 교체하지 않는다. 목표 변수·BSI mapping 차이를 명시. 2026-11 BSI 표본/KSIC 개편은 이번 평가기간에 포함되지 않음(2026-09까지).
