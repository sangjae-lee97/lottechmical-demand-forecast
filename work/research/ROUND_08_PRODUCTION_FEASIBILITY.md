# ROUND 08-A — 자동차 생산지수 확보와 탐색 결과

확인일 2026-11-03 KST / Codex. 기준 커밋 `7e5f447`을 fast-forward 반영한 뒤 실제 수집·분석했다. **공식 생산지수 57개월 확보 성공, BSI와 34개월 정렬 성공. 시점 엄격 예측평가는 미실행(`NO_VERIFIED_BACKTEST`).** 원본 관측 수치는 공개 저장소에 포함하지 않는다.

## 공식 원자료와 코드

출처는 국가데이터처 광업제조업동향조사, [KOSIS 대상 통계표](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1F02001&conn_path=I2)다. [공식 최근수록자료](https://kosis.kr/serviceInfo/newContrainDataDetail.do?boardIdx=1970002&boardOrgId=101)와 실제 통계표 화면에서 제목·최근수록월·갱신일을 함께 확인했다.

| 구분 | 실제 확인 결과 |
|---|---|
| 통계표 | `orgId=101`, `tblId=DT_1F02001` 시도/산업별 광공업생산지수(2020=100) |
| 지역 | SDMX 분류 `A=00`, 전국 |
| 산업 | SDMX 분류 `B=C30`, 자동차 및 트레일러 제조업 |
| 항목 | DSD `CL_ITEM / T10`, 생산지수(원지수) |
| 주기·단위 | `FREQ=M`, `2020=100`; DSD 단위 코드 `14101.ausgabe` |
| 실제 확보 | **2022-01~2026-09, 연속 57개월·57개 관측치** |
| 수록·갱신 | 최신월 2026-09, 화면·목록 자료갱신일 2026-10-30 |
| 접근 | 공개 화면에서 직접 선택 후 **SDMX 2.0 GenericData와 DSD** 다운로드 성공. 로그인·KOSIS 인증키 사용 없음 |

API 분류 인수 이름을 실제 API 응답으로 확인한 것은 아니다. 위 분류 코드는 공식 다운로드의 SDMX 차원·DSD로 검증한 것이며, 추정한 API URL이나 제삼자 코드에 근거하지 않는다. OPENAPI URL생성 화면에는 별도 사용자 인증키가 필요하다고 표시됐다. ECOS 키를 KOSIS에 전송하거나, 타인 키·숨은 인증 수단을 사용하지 않았다. 정식 공개 다운로드가 성공했으므로 신규 키를 요청하지 않았다.

GenericData의 SeriesKey에는 `FREQ/A/B`만 있고 ITEM·UNIT은 빠져 있다. 이를 조용히 무시하지 않고, 같은 선택 상태에서 받은 DSD의 **단일 항목 T10·단일 단위·단일 전국·단일 자동차 분류**와 화면 선택으로 보완했다. 검사 코드는 다른 항목·지역·산업·복수 계열·잘못된 DSD를 거부한다. GenericData만으로 항목을 독립 확인할 수 있는 파일이라고 주장하지 않는다.

화면 산업 트리의 하위 분류는 자동차용 엔진 및 자동차, 자동차 차체 및 트레일러, 자동차 신품 부품, 자동차 재제조 부품 제조업이었다. 따라서 **완성차 생산대수와 같은 집계가 아니며**, PC/ABS 소재 소비 톤수도 아니다. 전국 원지수는 연쇄 라스파이레스 방식이라는 공식 주석을 확인했다.

## 공표·수정·판본 검증

공식 화면 주석에서 확인한 내용:

- 최근 2개월 수치에 잠정치가 포함되며 추후 수정 가능. 이번 선택 화면의 **2026-08·09 열에 p)** 표시가 있었다. GenericData에는 이 표시가 보존되지 않아 별도 화면 근거 필드로 기록했다.
- 매년 1월분 공표 시점(2월말 또는 3월초)에 연간보정으로 최근 몇 개년 수치가 수정될 수 있다. 오래된 관측이라고 당시 값과 현재 값이 같다고 가정할 수 없다.
- 표 주석은 2015년부터 KSIC-10 기준 작성을 안내한다. 이번 생산계열에 BSI의 KSIC-11을 자동 적용하지 않는다.
- 별도로 보이는 2026-03-05 수정 공지는 **경기도 재고지수**에 관한 것이다. 이 전국 자동차 생산지수의 수정 이력으로 전용하지 않았다.

다운로드 헤더 `Extracted/Prepared`는 2026-11-03의 파일 생성 시각이다. 공식 공표일도, 최초 이용 가능 시각도 아니다. 헤더 시간대는 별도 미확인이므로 원문 문자열로 보존했다. 2026-10-30은 이번 표의 갱신일이며, 57개 관측 각각의 최초 공표일·수정일을 뜻하지 않는다. **개별 월 공표일·이용 가능 시점·원 발표 판본은 미확인으로 저장**했다. 현재 스냅샷의 출처와 당시 이용 가능 정보의 증거를 구분했다.

## 데이터 품질과 실제 정렬

정식 파일을 XML로 읽어 표·DSD·차원 코드·명칭·단위·월 주기·수치 형식을 검사했다. 2022-01~2026-09 기대 월 목록과 완전히 일치했고 **누락 0, 중복 0, 비수치/비유한 값 0**이었다. 모든 수치는 양수였고, 보간·대체·업종 합산을 하지 않았다. 화면에서 확인된 최신 2개월 잠정 플래그를 별도로 유지했다.

ECOS 자동차 BSI `512Y008 / BD / C3000`의 로컬 36개월 스냅샷을 그대로 사용했다. `forecast_target_month`와 생산 `period`를 조인한 실제 공통기간은 **2023-12~2026-09, 34개월**이다. 조사월은 이보다 한 달 앞선 별도 필드다. 2026-10·11은 생산 Y가 없어서 미정렬로 남겼으며 예측값·보간값을 정답으로 만들지 않았다. 정렬된 34개월의 전년동월비는 확보한 실제 전년동월 원지수로 모두 계산할 수 있었다.

## 탐색적 상관 결과 — 현재 조회 판본을 소급 이용

`corr(BSI_t, Y_(t+k))`의 Pearson 상관. BSI 기준월은 실제 동일월 공통기간 34개월로 고정했다. 양쪽 값이 있는 쌍만 사용하고 k를 탐색해 최적 시차를 고르지 않았다. 전년동월비는 `100 × (Y_s/Y_(s-12)−1)`이다. 이는 설문의 방향 응답을 물량 증가율로 변환한 것이 아니라, 별도 실측 생산 변환값과 비교한 것이다.

| 생산 상대월 k | 실제 쌍 수 | 원지수 수준과 r | 생산 전년동월비와 r |
|---|---:|---:|---:|
| -1 | 34 | -0.0407 | -0.1980 |
| 0 (동일 대상월) | 34 | 0.0664 | 0.0092 |
| +1 | 33 | -0.0797 | -0.2375 |

동일 대상월의 선형 연관은 이 표본에서 작았다. 연도별 동일월 전년동월비 상관도 2024년 -0.0082(n=12), 2025년 0.3334(n=12), 2026년 -0.0174(n=9)로 달랐다. 2023년은 1쌍이므로 상관을 계산하지 않았다. 계절성·조업일·명절·자기상관·표본수·잠정치·수정값 영향이 남는다. p값·유의성·인과성·선행성·예측력·추가 성능을 주장하지 않는다. BSI가 무용하다는 일반 결론도 아니다.

2026-10 조사 개편에 따른 BSI 단절 후보는 **전망 대상월 2026-11**이다. 이번 실제 정렬은 2026-09에 끝나므로 개편 후 관측은 0개다. 이번 결과로 개편 이후 안정성이나 KSIC-10/11 간 호환성을 검증할 수 없다.

## 예측평가 판단과 남은 조건

**현재 실행 불가: `NO_VERIFIED_BACKTEST`, 동일 origin의 검증된 입력 쌍 0개.** 정렬된 34개월은 BSI 개별 공표일도 미확인이고, 생산 t-12의 당시 공개판도 미확인이다. 현재 수정값을 소급해 baseline/+BSI 점수를 만들지 않았다. 모델 학습·튜닝·MAE·편향 비교는 수행하지 않았다.

다음 단계에는 원 발표 보도자료/판본, 이용 가능 시점, 수정 이력의 연결이 필요하다. 그 뒤에만 동일 정보집합의 계절 기준선과 BSI 1개 추가 모델을 비교한다. 상세 계약과 차단 검사는 `ROUND_08_TIME_ALIGNMENT.md`에 있다. 이 결과는 산업 생산지수의 탐색이며 고객별 C, 롯데 주문량, 채찍 효과 원인 복원의 성능이 아니다.
