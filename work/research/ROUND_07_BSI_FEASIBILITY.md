# ROUND 07 — 제조업 신규수주 전망 BSI 확보 가능성

확인일: 2026-11-03 KST / Codex. **판정: 향후 입력 후보로 조건부 유지, 현재 모형 투입은 보류.** 공식 정의와 자동차 세분화는 확인했지만 최근36개월 원자료·판본/공표 이력은 확보하지 못했다. 기존 모델·테스트·지원서·실험 결과는 변경하지 않았다.

## 1. 실제 확보 범위와 중단 사유

- 공공데이터포털 `한국은행_기업경기조사`(15059630)의 공식 메타데이터 HTML/Markdown 열람·저장 성공. 무료·JSON/XML·LINK형 제공으로 안내하며 포털은 이용허락범위 제한 없음으로 표기한다. 포털 자체에서36개월 CSV를 받았다는 뜻은 아니다.
- ECOS 홈페이지/API 안내는 접근되지만 웹 본문 추출에는 JavaScript 껍데기만 반환됐다. 공개 API `StatisticTableList/sample/json/kr/1/1000/` 요청은 HTTP200이지만 본문 **ERROR-301: sample은 최대10건 이내**였다. 허용 범위1~10 요청은 통계표 목록10개를 반환했으며 BSI 값36개가 아니다. 인증키 발급·로그인·샘플 제한 우회·전체 목록 반복 수집은 하지 않았다.
- 한국은행 전국 기업경기조사 **2026-09 PDF 18쪽, 2026-10 _vF PDF 19쪽**을 공식 첨부 URL에서 실제 다운로드했다. 텍스트 추출과 표 페이지 시각 확인으로 정의·자동차 행·보고 시점·표본 변경을 확인했다.
- 구조 확인용으로 **전망 대상월2026-10·11 × 제조업/자동차 =4행**만 별도 전사했다. 제조업 단일 지표의36개월 확보가 아니다. PDF 전체의 다른 수치는 검증된 시계열로 추출·채택하지 않았다.
- 최근36개월 목표 범위는 최신 전망 대상월2026-11을 끝으로 **2023-12~2026-11**(조사월2023-11~2026-10). 각 업종 확인 표본2개월, 미확보34개월. 원자료는 기업별 설문 미시자료가 아닌 공식 공표 시계열을 뜻한다.
- ECOS의 정확한 해당 통계표/항목 코드·관측월 인코딩·원계열/계절조정 구분·36개월 다운로드와 역사적 공표일 매핑은 미검증이다. 데이터 자체가 존재하지 않는다는 결론은 아니다. 제한된 샘플과 공식 PDF로 접근·구조를 확인한 뒤 추가 수집을 종료했다.

## 2. 지표의 정확한 의미

대상은 **한국은행 전국 제조업 신규수주 전망 BSI**다. 업황 BSI, 제조업 CBSI, ESI, 한국경제인협회 BSI 또는 산업연구원의 분기조사와 교체하지 않는다.

- 주기: 매월. 전망은 조사월 다음 달을 대상으로 한다.
- 단위: 지수, 대/톤/금액 아님. 업종별 BSI는 긍정 응답 비중−부정 응답 비중+100 방식이며 제조업 집계에는 업종별 GDP 비중 가중이 적용된다.
- 신규수주 질문은 **전년 동월 대비** 변화 방향의 확대/둔화 판단이다. ‘100보다 높다=전월 대비 주문 물량 증가’, ‘지수1p=물량1%’로 해석하지 않는다. 월간 지표라는 사실과 질문의 비교 기준을 구분한다.
- 전망이라는 정보 성격상 생산/수출 실적과 다른 기대 정보를 포함할 수 있다. 실제 선행성·추가 예측가치는 검증 전 가설이다.
- 자동차 업종 행이 같은 신규수주 **전망** 표에 있어 세분화가 가능함을 확인했다. 특정 완성차 A·성형업체 B 또는 PC/ABS 소재만의 조사 결과가 아니다. 자동차 업종의36개월 ECOS 세부시계열 접근은 미확인이다.

근거: 한국은행9월 PDF 표지, 인쇄p.3(물리5쪽), 업종별 전망표 인쇄p.12(물리13쪽), 조사 개요 인쇄p.13(물리14쪽). 10월 PDF 인쇄p.12(물리14쪽), 조사 개요 인쇄p.13(물리15쪽).

## 3. 기준월·공표일·사용 가능일·판본

현재 전사 표의 날짜·값은 아래 **최소 표본**으로만 검증했다. 36개월 학습 입력으로 사용하지 않는다.

| 2026-10 | 2026-09 | 제조업 | 91 | 2026-09-29 | 2026-09-30 00:00 | 9월 원본 첨부, KSIC-10 표본 |

공식 표지는 통신/방송/인터넷 취급06:00 이후, PDF의 ECOS 안내는 **보도 당일08:00 수록**이라고 명시한다. PDF 공개와 ECOS 수록 시점을 같게 두지 않는다. 이번 JSON 표본은 과거 실제 수록 로그까지 확인하지 않았으므로 프로젝트의 보수적 다음날 규칙을 사용한다.08:00을 적용하려면 해당 채널·일자 수록과 예측 origin을 별도 확인한다.

조사기간은9월10~17일,10월14~21일. 예측 대상월과 조사월, 전년 동월 비교 기준, 공표/입수 시점을 모두 별도 필드로 저장한다. 예를 들어9월29일 공표된 다음10월 전망을9월초 예측 입력으로 넣으면 누수다. ECOS TIME 필드가 전망 대상월인지 조사월인지는 실제 series 조회 후 대조해야 한다.

파일명 `_vF`는 확보한 첨부의 판본 식별자일 뿐, 이전 첨부의 존재·정정일·숫자 변경 이력을 검증했다는 뜻은 아니다. 같은10월 전망값이9월/10월 PDF의 비교열에서 일치함은 확인했으나 전체 개정 이력·역사적 판본은 미확보다. 각 원본 SHA-256·URL·다운로드일과 추출 방법은 로컬 manifest에 보존한다.

## 4. 핵심 품질 이슈 — 2026년10월 조사 개편

10월 PDF ‘알리는 말씀’(물리2쪽)에서 다음을 직접 확인했다.

- 표본 모집단 기반2021년→2024년, 표본 수3,524→3,639개.
- 2026년10월 조사 결과부터 새 표본. 산업분류 KSIC-11 반영.
- 한국은행은10월 이후와9월 이전 지수 비교에 표본 개편 영향이 포함될 수 있다고 안내한다.
- 전망표의11월 열에는 신규표본 조사결과 각주가 있고,10월 열은 이전 조사 전망이다. 따라서 전망 대상월 기준 **2026-11부터** 새 표본이라는 점을 반영해야 한다. 조사월 기준 개편 경계2026-10과 혼동하지 않는다.

이 변화는 단순 수치 정정이 아니라 비교가능성 문제다.36개월을 확보해도 개편 전후를 무검증 단일 정상계열로 취급하지 않는다. 연결계열·정의 변경·가중/표본 차이·다른 기간의 개편 여부를 확인하고, 개선/급변을 곧바로 수요 변화로 해석하지 않는다.

현재 검사: 원본 PDF 다운로드·텍스트 추출·두 표의 시각 검증 PASS;4행 지표/단위/대상월/조사월 일치·업종별 중복 없음·범위0~200·이용 가능일이 공표일 이후 PASS.36개월 연속성 FAIL, ECOS 정확 코드/셀 대조 미수행, 전체 개정 이력 미확인. 기초 표본 검사는 모델 적합성/예측력 검증이 아니다.
