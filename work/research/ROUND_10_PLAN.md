# ROUND 10 — 최초 실측 결과 미공표 시점의 예측 고정(Prospective Lock)

작성: 2026-11-03 / ChatGPT Orchestrator
상태: **실험 프로토콜, 아직 예측 실행·수치 고정·성과 평가 미완료**.
근거: `ROUND_09_INDUSTRY_PROXY_REPORT.md`, `ROUND_08B_EXPLORATORY_REPORT.md`, `ROUND_08_TIME_ALIGNMENT.md`.

## 1. Why now?

기존 Round 08-B의 12개월 보행 평가는 당시 공표판이 아닌 최신 KOSIS/ECOS 스냅샷을 소급 사용한 탐색이었다. 과거판본 누수를 확인/제거한 실시간 백테스트로 간주할 수 없다. 이제 **실제 아직 발표되지 않은 생산지수의 값**을 미래에 확인하기 전에 현재 입력과 모델 예측을 불변으로 봉인하는 전향적 평가를 시작한다. 기존 연구·점수와 경쟁/대체하지 않는다.

Round 09 데이터: C222(플라스틱 제품 제조업), C303(자동차 신품 부품 제조업) 2022-01~2026-09 각각 57개월 확보. C303은 C30의 하위 업종이며, C222은 자동차 외 용도를 포괄. 둘 모두 고객 PC/ABS 소비 톤수가 아니다.

## 2. 사전 지정 타깃/설명변수

- **Y1: C303** 자동차 신품 부품 제조업 생산지수(원지수, 2020=100)의 전년동월비 `g_t = 100*(P_t/P_(t-12)-1)`.
  - X1: ECOS `512Y008 / BD / C3000` 자동차 업종 신규수주 **전망** BSI, `forecast_target_month=t`으로 조인.
- **Y2: C222** 플라스틱 제품 제조업 생산지수의 같은 방식 전년동월비 `g_t`.
  - X2: 같은 ECOS 표 `512Y008 / BD / C0000` 제조업 전체 신규수주 **전망** BSI. 플라스틱 업종 전용 BSI의 성격으로 오해하지 않는다.
- X/Y를 동시에 자동 최적선택하지 않는다. 두 타깃과 두 매핑 모두 결과 확인 전에 고정. 목표월 `2026-10`과 `2026-11`만 설정.
- **2026-10**: 2026-11-03 실행 시 이미 월이 끝났으나 Y가 미공표인 경우 **nowcast of unreleased activity**.
- **2026-11**: 2026-11-03 실행 시 대상월이 진행 중이므로 **within-month prospective forecast**. 이 원점은 **11월 1일 00시의 월초 예측이 아니며**, 추후 1개월 선행 예측성과로 둔갑시키지 않는다.
- 2026-11을 전망한 BSI는 2026-10 조사에서 발표, 기존 2026-11 타깃부터 표본/KSIC-11 개편 경계다. **새 표본 값의 학습분포 이탈 위험 표시**.
- KOSIS 2026-10/11 실현값의 발표 여부를 새로 조회하거나 임의로 만들지 않는다. 현재 로컬 입력 스냅샷의 마지막 생산 기준월이 `2026-09`임을 확인하고 **목표월 Y가 존재하면 봉인 실험 중단**.

## 3. 입력과 실제 예측 시점 보전

- 현재 로컬의 공식 KOSIS C222/C303 SDMX·DSD와 ECOS 36개월 BSI 스냅샷만 사용. 기존 원자료·정규화 파일 변조 금지.
- 입력 파일 SHA-256, 실제 생성시각(오프셋 포함 ISO 8601, KST), 마지막 확보 생산월, BSI 두 월 값의 원 발표 PDF/게시일 증거, 사용 모형/설정 및 소스코드 Git commit SHA를 기록.
- **실행 원점(origin)은 실제 실행한 날짜와 시간.** 2026-10·11의 명목 월초 origin과 동일시하지 않는다. 해당 시점에 사용 가능한 자료임은 현재 스냅샷의 2026-11-03 확보와 2026-09 생산지수 2026-10-30 갱신, BSI의 2026-09-29/10-29 공식 발표에 근거해 제한적으로 주장한다. 개별 과거판본을 복원했다고 주장하지 않는다.
- ECOS 2026-10 전망 및 2026-11 전망은 최근 공식 PDF와 대조했던 4개 값을 확인하며, 새 시계열 다운로드로 옛 값을 덮어쓰지 않는다. 2026-11 BSI 표본개편 명시.
- 대상월 실현 지수는 미래 발표되므로 현재 예측값의 계산/모델 선택/로그에 포함시키지 않는다.

## 4. 사전 지정 예측모형 (변경·튜닝 금지)

각 타깃별 고정 3모델:
1. `seasonal_naive`: `g_hat_t=0`.
2. `past_yoy_mean`: 같은 타깃과 매핑 BSI가 함께 있는 과거 공통 패널의 `g_s` 평균.
3. `bsi_ols`: 같은 과거 공통패널에서 절편 포함 `g_s=a+b*BSI_s`, 미래 X_t를 대입.

모든 학습 행은 **`s <= t-2`**로 고정. Oct 타깃이면 2026-08 이하, Nov 타깃이면 2026-09 이하; 현재 시점에 실제 확보된 스냅샷만 학습한다. X와 Y 동일 목표월 조인, BSI 조사월 t-1 구분. 최소 학습 12행, 상수 BSI·분모 부재·중복월/해시 불일치시 fail-closed. 원점별 계수와 입력계열 검사 및 합성 fixture 테스트 필수. Round 08-B 코드/검증 게이트를 변경하지 않고 재사용하거나 별도 구현.

예측치는 **생산지수 전년동월비 `% YoY`**. 미래 Y 미공표이므로 **MAE/RMSE/편향·개선율을 아직 계산하지 않는다.**

## 5. 변조방지 및 앞으로의 평가

- 각 2타깃 × 2목표월 × 3모델 = **12개의 사전 예측**을 생성하고, 로컬 `work/data/local_only/round10_prospective/`에 canonical JSON + SHA-256 + input manifest + model params 저장.
- GitHub에는 공식 개별 관측값을 올리지 않는다. 사전 잠금 증거로 **12개 예측 JSON의 SHA-256, 2개 목표월, 2개 타깃, 모형 이름, 실제 봉인 시각, 코드 커밋, 인풋 해시, 알고리즘 명세**를 보고서/커밋에 공개한다. 사후 점수를 유리하게 만들기 위해 JSON 다시 생성·수정 금지. SHA만으로 과거 실제 실행 시각을 입증하지 못하므로 Git commit 시각을 별도 신뢰 경계로 표기한다.
- 나중에 2026-10/11 실제 공식 생산지수가 각각 **처음 발표**되면 그 첫 공개 판본의 값/수정 여부·발표일과 별도 SHA를 보관해 **잠긴 예측**만 채점한다. 재학습·사후 수치 교체 금지. 잠정/확정이 바뀌면 나란히 판본별로 별도 채점.
- n=2개월×2업종은 연구용 예비 점검일 뿐 통계적 예측 성능·실무 효용 입증 아님. 장기간 후속 prospective origin을 쌓아야 함.
- 엄격 과거판본 보행 검증은 `NO_VERIFIED_BACKTEST` 유지. 앞으로 prospectively locked forecast가 생겼다고 과거 Round 08-B를 엄격 backtest로 소급 인증하지 않는다.
