## 0. 실험 목적과 과잉해석 방지

- ROUND 12-A 고정 12개월 2025-10~2026-09에서 **C303** 과거 평균 MAE 8.6411p.p. vs BSI OLS 9.1629p.p. (BSI −6.04% skill); **C222** 과거 평균 MAE 7.5501p.p. vs BSI OLS 9.3109p.p. (BSI −23.32% skill).
- C303의 BSI는 YoY 상승/하락 방향 8/12, 과거 평균 4/12를 맞혔으나 MAE는 더 나쁨. C222의 평균/BSI 예측 편향이 +6.4544/+8.5612p.p.이고 BSI 승패 2/10. **이는 새로운 실험 가설의 근거이지 개선 효과를 확인한 증거는 아님.**
- **사후 설계**: 이번 후보들은 12-A 결과를 보고 제안한 만큼 동일 12개월에 대한 결과는 **탐색적 최적화**로만 보고한다. 실제 미래 데이터에 대한 독립 성능 주장, 확증적 전향검증, 통계적 유의성 주장 금지.
- 산업 생산지수 YoY는 실제 고객별 PC/ABS 소비량이나 롯데케미칼 주문톤이 아니다. **예측률 XX%** 표현 금지.

## 1. 사전 지정한 두 가지 가설

- **H1 — 최근 추세를 덜 낡은 평균으로 반영:** C222의 고정 과거 전체 평균이 실측 YoY의 최근 하락을 과소반영해 양의 편향을 만들 수 있다. 업종별 최근 6개월 또는 12개월 **훈련 가능한 Y의 평균**을 기준선으로 고정 시험한다. 반드시 C303에도 같은 규칙을 적용해 일방 선택하지 않는다.
- **H2 — BSI 회귀의 과한 진폭 축소:** C303에서 방향 적중과 MAE가 엇갈리는 상황을 진단하기 위해 `BSI_50_50 = 0.5*BSI_OLS + 0.5*past_yoy_mean`을 고정 시험한다. 계수 0.5는 **결과를 보고 새로 학습·선정하지 않으며** C222에도 그대로 적용한다. 방향 정보가 남는지, MAE·편향이 개선되는지 평가한다. 결과에 따라 혼합비 변경 금지.
- 과거 평균·BSI OLS·계절 Naive·t-2 YoY 유지의 기존 Round 12-A 정의도 모두 그대로 재현한다. 결과가 좋더라도 재추정한 Round 12-A 결과를 대체하지 않는다.

## 2. 입력과 유효성

- API 호출·새 데이터 다운로드 없이 기존 로컬 `work/data/local_only/round09_industry/` KOSIS `C303,C222` SDMX와 `round07c_ecos/` BSI 정규화/원문 및 기존 SHA 매니페스트만 읽는다.
- C303→ECOS `512Y008/BD/C3000`; C222→`512Y008/BD/C0000`. BSI는 `forecast_target_month=t`, 조사월=t−1.
- 평가 타깃 `y_t = 100*(P_t/P_(t−12)−1)` % YoY. 같은 달 Y는 채점에만 쓰고, 다른 모델에도 포함시키지 않음.
- 개별 원점 t에서 훈련 상한 **target month `t−2` (inclusive)**. 기존 12-A 학습 공통 월은 해당 원점 첫 21행, 최종 32행. 최근 평균은 **그 원점에서 실제 학습 대상이 된 마지막 6/12개 Y만** 사용, 미래 행/평가 집합 오차 사용 금지.
- 주요 평가 12개월 `2025-10~2026-09` 완전히 고정. 2026-08/09 제외 **같은 예측 10개월 민감도**, 재학습 없음.
- 추가 탐색 구간 `2025-01~2026-09` 총 21개월(첫 타깃 학습 공통 12행, 최종 32행; 기존 12개월 포함). 이것은 서로 다른 독립 테스트 세트가 아니며 모델 선택 후 성능 증명으로 취급하지 않는다. 필요하면 2025-01~2025-09 9개월과 주 12개월을 나눠 **서술형 기간 안정성 진단**; 성능 좋은 구간만 홍보 금지.
- 당시 최초 공표·수정 판본을 검증하지 못함: `HINDSIGHT_CURRENT_VINTAGE_EXPLORATORY` / `NO_VERIFIED_BACKTEST` 그대로 유지.

## 3. 모델 정의 (결과 확인 전 고정)

모든 업종 동일, 매 목표월 t마다 같은 공통 `train_yoy`와 `train_bsi`를 사용:

1. `seasonal_naive` = 0
2. `past_yoy_mean` = 전체 공통학습 YoY 평균
3. `bsi_ols` = 기존 절편 포함 OLS 훈련, 현재 X_t 입력
4. `yoy_last_available_tminus2` = y_(t−2) 유지 (기존 보조 기준선)
5. `rolling_yoy_mean_6` = 직전 학습 가능한 6개 YoY 평균
6. `rolling_yoy_mean_12` = 직전 학습 가능한 12개 YoY 평균
7. `bsi_blend_half` = 0.5*BSI_OLS + 0.5*past_yoy_mean

예측 모델 7개 모두 같은 평가 월에 대해 MAE, RMSE, bias (예측−실측)를 산출. 데이터에서 `0.5`, `6`, `12`를 최적화하거나 사후 비교해 최적 하나만 결과로 내지 않는다. 2025-01 earliest origin도 12행 훈련 가능해야 하고, BSI 상수/비유한/월 누락은 fail-closed.

## 4. 필수 수치 분석

- 각 업종 × 모델의 12개월 MAE/RMSE/bias와 평가월 n, 10개월 잠정 제외 결과, 확장 21개월 참고 결과.
- `past_yoy_mean` 기준 각 새 모델 `ΔMAE`와 skill%, `seasonal_naive` 기준도 병기. **기존 `bsi_ols`를 가상의 개선 대상으로 선택해 성과를 과장하지 않음.**
- C303: `past_yoy_mean`, `bsi_ols`, `bsi_blend_half`의 방향 적중 수/분모, MAE, 편향을 함께 공개. 방향 적중 개선 ≠ 크기/MAE 개선.
- C222: actual YoY의 평가기간 평균과 훈련 평균의 괴리/상대 부호, 각 모델 편향과 과대예측 월 수를 **파생 집계**로 진단. 경제적 원인은 미검증 가설로만.
- 12개월 각 평가월의 절대오차 차이를 `past_yoy_mean`과 짝지어 wins/ties/losses, leave-one-month-out min/max skill을 **모든 신규 후보**에 대해 요약.
- 보조 지표: 2025-01~2025-09(9개월) / 2025-10~2026-09(12개월) 평가를 나눠 기간 민감도, 2026-08/09 잠정 제외. 시간 의존성과 소표본 때문에 유의성·재현 가능 성능 증명 아님.
- 기존 Round 12-A 결과가 코드/입력 동일조건에서 부동소수점 허용오차 내에 재현되는지 먼저 확인. 불일치면 **새 모델 비교 중단**하고 보고.
