# 주문 신호에서 수요 복원 — 식별 가능성 검토 V1

2026-11-02 KST / Round 03 필수 수정 반영. 수급식·반례는 논리 검토, 실험은 합성 자료만 사용했다. 현행 목표는 다음 1개월 C이며 [실행 계약](../work/prototype/README.md)을 함께 참고한다.

## 1. 복원할 ‘수요’를 먼저 제한한다

| 층·주체 | 변수·단위 | 의미와 구분 |
|---|---|---|
| 최종 소비자 | 희망 구매, 구매/판매 대수 | 원하지만 품절로 못 산 양은 판매실적에 나타나지 않을 수 있음 |
| 완제품 제조사 A | 생산 P, 대/월 | 실제 생산은 판매·주문·미충족 소비자 수요와 다름. 작업상 End Customer로 정의 |
| 부품업체 | 부품 생산, 개/월 | A 납품과 재고 변동·다른 고객 납품을 분리해야 함 |
| 소재 가공업체 B | 실제 소재 투입 C, 톤/월 | 본 연구의 복원 대상. A용 부품 생산에 귀속되는 전체 공급사 PC/ABS 투입량. B가 부품업체와 같을 수도 있음 |
| B의 구매 | 소재 주문 O, 톤/발주월; 요청납기 별도 | 재고 축적·묶음발주·변경·취소·미입고 영향 포함 |
| 롯데 출하 / B 입고 | S / R, 톤/월 | S와 R은 운송·검수·기간 경계 때문에 다를 수 있음. 롯데 입고분은 B 전체 공급사 입고의 일부 |

‘잠재 수요’는 관측되지 않은 C를 뜻하는 **작업상 잠재변수**로 제한한다. 공급제약이 없었다면 필요했을 C* 또는 최종 소비자의 미충족 구매 의사까지 복원했다고 주장하지 않는다. 입고·재고로 식별되는 실제 소비와 미충족 수요는 다른 대상이다.

## 2. 관측변수와 수급 경계

먼저 B 한 사업장·한 소재 재고 경계 전체의 소비를 계산하고 A 귀속을 분리한다. 전체 재고만 알면서 A 귀속 소비까지 식별했다고 할 수 없다.

- I_t: t월 말 경계 안 원재료 재고, 톤. I_(t-1)은 기초 재고.
- R_t: 같은 기간 실제 입고, **전체 공급사** 합계. 주문·롯데 출하를 그대로 대신 넣지 않음.
- C_t: 재고에서 생산으로 실제 불출된 소재, 톤. 공정 손실은 투입량에 이미 포함될 수 있음.
- M_t: 반품 회수·사업장 간 이동 등 구매 입고 외 순유입, 부호 있는 톤. End Customer A와 기호를 분리했다.
- L_t: 생산 불출과 별개인 창고 폐기·분실 등 재고 감소, 톤. C와 중복 계산 금지.
- O_t: 구매 주문 순증, 취소·변경을 반영한 전체 공급사 주문. 발주월 기준.
- W_t: 주문됐으나 아직 입고되지 않은 잔량(공급사 미출하+운송 중), 톤. 주문·입고와 같은 범위.
- 잠재/미확보: C, C의 A 귀속, C*, 고객 정책, BOM·수율·거점 배분, 공급 점유율. 관측 조건에 따라 I·R·W도 잠재변수다.

물량 보존식:

`I_t = I_(t-1) + R_t + M_t − C_t − L_t`

따라서 `C_t = R_t − (I_t − I_(t-1)) + M_t − L_t`.

모든 주문 변경을 O에 반영하고 같은 범위의 미입고 잔량을 관리하면 `W_t = W_(t-1) + O_t − R_t`이므로:

`C_t = O_t − ΔW_t − ΔI_t + M_t − L_t`.

재고를 늘리기 위한 입고는 실제 소비보다 크고, 재고를 줄이는 달은 입고보다 소비가 클 수 있다. 임의 고정 lag로 O를 R로 바꾸는 것은 관측 사실이 아닌 가정이다. 미납·부분납·취소가 있으면 고정 리드타임만 알아도 충분하지 않다. 음수 C가 나오면 자동으로 0 처리해 숨기지 말고 단위·누락·시간 경계 오류로 표시한다.

롯데가 관측하는 자사 주문 O_LC만 있으면 위 식의 전체 공급사 O와도 다르다. 공급사 전환·배분율 변화가 추가 잠재변수가 되므로, 자사 주문을 전체 소비로 확장할 때 고정 공급비중을 사실처럼 가정하지 않는다. 리드타임과 묶음발주는 관측 주문/입고의 시점과 생성 정책에 반영되며, 수급식에서 임의로 각각의 효과를 더하고 빼는 항이 아니다.

## 3. 관측 조건별 결론

| 확보 조건 | 추정 가능한 것 | 필요한 추가 가정/관측 | 식별 불가능하거나 주의할 것 |
|---|---|---|---|
| 롯데 관측 후보 O_LC+S_LC, 간헐 고객 보고·생산 대리지표 | 공급비중·원단위·정책 가정하의 소비 대응 추정과 불확실성 | 보고 시점·고객 귀속·계약/권한 확인, 공급비중 민감도 | 자사 주문/출하는 전체 O/R가 아님. 보조 신호 없이 단기 C는 식별 불가. 후보는 실제 접근 확인 아님 |
| B 전체 O만 | 주문 추세·발주 간격·묶음 패턴 | 초기 상태·정책·리드타임·취소 등의 가정 | 월별 타이밍·단기 변동 분해는 일반적으로 식별 불가. 장기 평균은 아래 조건부 가능 |
| O+I | 재고 변화는 관측. 입고 가정에 따른 C 시나리오 | R 또는 완전한 W 이력, M·L 및 측정 경계 | O+I만으로는 일반적으로 C 식별 불가. 주문=입고를 가정한 경우에만 단순식 성립 |
| I+R+M+L | 같은 경계의 총 실제 생산불출 C를 회계적으로 계산 | 수량 스냅샷 정확성·경계 일치·주기 일치. A 귀속은 부품별 불출/배분 추가 | C*·소비자 희망 구매는 불가. ‘AI가 복원’이 아니라 회계 기준값으로 먼저 사용 |
| O+I+P | 완제품 생산과 소재 소비의 일관성·가능 범위 검토 | A/B 매핑, 차종·부품 믹스, 소재 채택, 원단위·수율·공정/재공품 시차 | 총 P만으로 kg/대·ABS 비율·시차를 동시에 식별 불가. 주문·원재료 수급 부족은 여전히 남음 |
| I+R+M+L+P+BOM/귀속 | C 계산과 생산 기반 소요의 대조, 차이 원인 후보 | 생산 이전 소재 불출·부품 재고·공정 손실·회수의 정의 | 두 계산 차이를 모두 채찍 효과로 해석할 수 없음. 원인별 인과 기여도는 별도 자료 필요 |

**직접 반례:** O=100톤, 기초·기말 재고가 모두 20톤, M=L=0인 한 달을 보자. (a) R=100이면 C=100, (b) R=40이면 C=40이고 미입고 잔량이 60 늘어난다. 관측 O·I는 완전히 같아도 실제 소비가 다르다. 그러므로 O+I만으로 C를 확정하는 모델은 자료 밖 가정을 사용한다.

가능 범위만 알려진 경우에는 점추정 대신 구간·시나리오를 낸다. 예를 들어 R∈[40,100], ΔI=0, M=L=0이면 C∈[40,100]이다. 반대로 아무 제약도 없으면 좁은 구간을 임의로 만들지 않는다. 이 예시는 합성 설명이며 실제 수치를 뜻하지 않는다.

**장기 평균의 예외:** T개월 합산하면 `평균 C = 평균 O − (W_T−W_0)/T − (I_T−I_0)/T + 평균(M−L)`이다. I/W가 유계이고 기타 유출입 평균 효과를 보정할 수 있으면 전체 주문과 소비의 장기 평균이 가까워질 수 있다. 이는 월별 타이밍·변동의 복원과 다르다. O_LC만으로는 공급비중 변화가 추가로 남고, 유한 48개월에서 수렴했다고 보장하지 않는다.

## 4. 생산량→소재량 연결의 한계

제품 k의 생산 P_k × 적용 부품 수 × 해당 소재 kg/부품 ÷ 1,000을 합하면 **가정한 표준 소요량**이다. 제조 이전 불출·공정 재고·스크랩·회수·재질 변경·외주를 반영해야 실제 월별 C와 비교할 수 있다. 순제품 중량 기반인지 총투입 원단위인지 먼저 정해 수율을 중복 적용하지 않는다.

산업 국가 합계에서 A로 내려가려면 A의 생산비중·지역·거점·차종 믹스가 필요하다. A에서 B로 가려면 부품 수주 배분·자체 생산/외주 비율이 필요하다. B에서 롯데 공급분으로 가려면 실제 공급비중과 주문 정책이 필요하다. 공개 판매대수 하나에 임의 상수를 곱한 값은 실측 수요가 아니다.

## 5. 채찍 효과는 가설이며, 원인 분해와도 다르다

Lee·Padmanabhan·Whang(1997)은 주문 정보 왜곡과 수요 신호 처리·할당 경쟁·묶음 주문·가격 변동을 분석한다. 이 일반 메커니즘은 이번 연구 질문의 근거이며 롯데에서 같은 현상이 발생했다는 증거는 아니다. [원 논문 초록](https://pubsonline.informs.org/doi/10.1287/mnsc.43.4.546) 확인일 2026-11-02; 유료 전문에는 의존하지 않았다.

같은 수량 단위·같은 고객/소재 범위·같은 주기의 O와 C가 있을 때 `Var(O)/Var(C)`를 변동 증폭의 기술통계로 볼 수 있다. C 분산=0이면 계산하지 않는다. 평균·범위·추세·표본 길이를 함께 표시하고, 비율>1만으로 리드타임이나 재고 정책의 인과 효과를 확정하지 않는다. 월별 집계는 주간 묶음발주 현상을 가릴 수 있다. 단순 평활화로 분산을 낮추는 것은 정확한 복원을 뜻하지 않는다.

## 6. 복원 검증과 미래 예측 검증을 분리한다

### A. 현재 공개 실측에서 허용할 주장

공식 소재 용도·공개 지표의 값/단위/판본·공표 시점은 검증 가능하다. 현재 확보 자료에는 같은 고객의 O·R·I·C 정답이 없어 실제 복원 정확도·실제 채찍 효과·미래 고객 수요 개선은 검증 불가다. 생산/BOM 추정값을 정답으로 쓰면 검증 이름도 ‘소요 추정값과의 일치’로 제한한다.

### B. Round 03 최소 상태공간 모형과 실제 실행

숨은 상태 x_t=C_t. 전이식 `C_t=C_(t-1)+w_t`, w~N(0,36 톤²). 초기 N(100,2500). 최소 모형은 소비 상태 하나이며 I를 추정하는 다변량 모형이 아니다. I/R 전체 관측이 없으므로 간헐 재고는 상태 관측으로 쓰지 않는다.

관측식은 `O_LC,t / p = C_t + v_o,t`, v_o~N(0,45²), `생산대리지표_t × b / 1000 = C_t + v_p,t`, v_p~N(0,12²)이다. b=2kg/대는 가정이며 p=.30/.45/.60 민감도를 계산한다. 참 p=.45 조건을 주 실험으로 사전에 정했고 숨은 소비로 p나 잡음을 맞추지 않았다. 주문 왜곡을 잡음으로 근사하며 입고와 같다고 두지 않는다. 묶음 주문의 상관·비정규성, 계절성·정책 변화는 이 근사에 맞지 않을 수 있다.

생산 관련 대리지표는 한 달 늦게, 재고 보고는 분기마다 두 달 늦게 도착하는 합성 조건이다. 실제 그 자료를 롯데가 받을 수 있다는 증거는 없다. 매 origin에서 available_at 이하 자료만 남겨 측정 대상월 순으로 필터를 재실행하고 그 origin의 현재 상태만 출력한다. 과거 보고의 지연을 현재 소비 관측으로 잘못 붙이지 않는다. 미래 관측으로 과거 origin 추정치를 고치지 않는다. 파라미터·원단위·공급비중은 전체 기간에서 추정하지 않는 고정 사전 가정이며 실측 재추정 시에도 origin 이전 자료만 허용한다.

식별의 추가 근거는 시점과 환산 가정이 있는 대리지표다. 최근 3개월 이내 대리지표가 없으면 NOT_IDENTIFIED로 상태 평균·구간을 비운다. 단순 주문 평균은 공급비중 가정에 조건부인 기준 시나리오로 남긴다. I만 보고 C를 측정했다고 하지 않는다. S_LC도 전체 R이 아니므로 이번 필터에 넣지 않는다. 출력은 원인별 재고·리드타임 효과를 유일하게 분해한 값이 아니다.

48개월×20시드, 마지막 12개월을 미래 C 정답으로 평가했다. 각 origin 35~46(0부터 세는 월)에서 다음 한 달만 예측한다. 세 방법은 (1) 최근 3개월 자사 주문 평균/p, (2) (1)과 이용 가능한 최근 3개 대리지표 환산 평균을 1/2씩 결합, (3) (2)와 현재 필터 상태를 1/2씩 결합이다. 모두 고정 식이며 학습/튜닝에 참 C를 쓰지 않는다. (2)(3)은 같은 관측의 함수라 정보가 새로 생기는 것이 아니며 차이는 구조적 사전지식·가중 방식의 효과다.

공급비중 .45에서 기본 조건 MAE는 (1)49.872, (2)32.495, (3)28.282톤. 기간30 이후 대리지표 +50% 오염 조건에서는 49.872/42.127/47.447톤이었다. 상태 추가가 직접 활용보다 악화될 수 있다. 상태 단독의 명목 95% 가우시안 다음달 구간 포함률은 기본45.0%, 오염21.7%로 부족했다. 이 구간은 결합 예측(3)의 구간도 아니고 공급비중·원단위의 체계적 오차를 포함하지도 않는다. 실무 확률 보증으로 사용하지 않는다.

검증은 단위·중복·수급식, 미래/미입수 관측 변경에 대한 예측 불변성, 입고 없는 재고·자사 출하의 필터 비사용, 주문만 있는 조건의 기권, 동일 시드 재현을 포함한다. 구현·실행 명령·모든 오차·공급비중 민감도는 [README](../work/prototype/README.md)와 [RESULTS](../work/prototype/results/RESULTS.md)를 참고한다.

합성 생성기는 계절·추세·충격의 C와 재고 보충·2개월 묶음발주·2개월 입고지연을 만든다. 필터는 이 정책을 역산하지 않는 랜덤워크다. 다만 대리지표를 C에 잡음을 더한 단순 환산관계로 생성했으므로 실제보다 유리한 합성 가정일 수 있다. 참 C는 생성기 및 사후 평가에만 있고 forecast 함수는 관측 이벤트만 받는다. 진짜 고객 성능·재고 절감·채찍 효과의 실제 원인을 입증하지 않는다.
