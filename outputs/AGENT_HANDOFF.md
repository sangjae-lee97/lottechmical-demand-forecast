# 웹GPT · Codex · Claude 협업 안내

## 공통 배경

롯데 AX Challenge 2026의 롯데케미칼 첨단소재 수요예측 AI 기획 과제를 준비한다. 마감은 2026-11-04 23:59 KST. 사용자는 환경 컨설팅 인턴 중 롯데케미칼 공장 인허가 관련 업무를 접했으며, 고객 데이터와 수요예측 실무 경험은 없고 AI 도움으로 코딩한다.

필수 제출: 정의·기획안 / 구축방안 / AI 역량 각 최대 3,000자. 포트폴리오는 필수 표시가 없으며 100MB 이하. 본선에는 구체화된 과제와 현장 데이터가 제공된다고 안내되어 있다.

실제 거래 고객·예측 성능·사업 효과를 임의로 단정하지 않는다. 출처, 가정, 실제 측정 결과를 구분한다. 제출·계정 조작은 작업 범위에 포함하지 않는다.

## 웹GPT에 전달할 초기 요청

당신은 이 프로젝트의 orchestrator다. Codex는 primary executor, Claude는 independent reviewer다. 첨부한 PROJECT_PLAN.md를 기준으로 우선순위와 단계별 작업을 조율해 달라. 첫 단계는 소재·산업 선택과 예측 대상 정의다. PC/ABS 자동차용과 ABS 가전용은 후보이며 아직 확정하지 않았다. 예선 필수 답변과 이해 가능한 작은 시연을 우선하고 범위를 확대하지 말아 달라. 각 작업 지시에는 목표, 입력 자료, 산출물, 완료 기준을 포함해 달라. 리뷰 의견이 충돌하면 쟁점과 판단 근거를 정리해 달라.

## Codex 작업 지시 형식

- 작업 ID / 목표
- 입력 자료와 확정된 결정
- 작업 범위와 이번에 제외할 기능
- 필요한 산출물
- 완료 기준
- Claude가 확인할 핵심 쟁점

## Claude에 전달할 검토 요청

당신은 독립 검토자다. 실행자의 결론을 그대로 받아들이지 말고, 공식 과제 요구사항과 첨부 결과물을 기준으로 검토해 달라. 특히 (1) End Customer 정의, (2) 소재 소비량과 주문량의 구분, (3) 공개 지표를 고객사 수요로 연결하는 가정, (4) 합성 데이터 성능의 과장, (5) 시간 순서와 데이터 누수, (6) AI 에이전트 역할의 실체, (7) 사용자의 실제 경험·기여 표현을 확인해 달라. 불확실한 내용은 사실 오류와 구분해 질문으로 남겨 달라.

의견마다 다음을 제시해 달라:
- 중요도: 제출 전 필수 수정 / 개선 권고 / 질문
- 대상 문장·파일·위치
- 문제와 근거
- 가능한 최소 수정

검토 결과는 work/reviews/에 보관하고, Codex는 의견별 수용·부분 수용·보류와 이유 및 수정 내용을 기록한다. 해결되지 않은 방향 결정은 웹GPT와 사용자에게 전달한다.

## 결과 전달 패킷

1. 이번 작업의 결과
2. 생성·변경한 파일
3. 사용한 출처와 데이터
4. 사실 / 가정 / 미확인 사항
5. 실행·검증 결과
6. 다음 단계에 필요한 결정

초기 상태(2026-10-30 계획 작성 시점): 계획과 폴더만 생성. 아래 갱신 이력을 우선 참고한다.

## 2026-11-02 갱신 — 연구 방향 V1 조사 완료

사용자/전달된 orchestrator 지시: 연구 방향을 **채찍 효과에 따른 주문 신호 왜곡과 잠재 수요 복원**으로 설정. 이는 공식 출제 의도를 확정한 것이 아니다. Codex는 조사·범위·식별 가능성·검증 설계까지만 수행했다. 외부 Claude 호출·대체 에이전트·모델 코딩·합성 데이터 생성·프로토타입 구현·지원서 조작은 없다.

### 핵심 결론

- 자동차용 PC/ABS·가상 A–B 경로 추천 유지. 공개 월별 회사 신호·기존 조사 재사용이 근거이고, 고객 소재 소비의 실측 정답을 확보했다는 뜻은 아니다.
- 복원 대상은 A 제품에 귀속되는 B의 **실제 소재 투입 C(톤/월, 모든 공급사 기준)**. 최종 소비자의 희망 구매·품절로 실현되지 않은 수요 C*와 구분한다.
- 주문 O만, 또는 O+재고 I만으로는 C가 일반적으로 유일하게 식별되지 않는다. 실제 입고 R·수량 재고·반품/이동·손실이 같은 경계로 있으면 소비를 회계적으로 계산할 수 있다. A 귀속에는 별도 매핑 필요.
- 완제품 생산량은 BOM·소재 선택·수율·공정시차가 있어야 표준 소요량으로 환산할 수 있고 실제 소비의 직접 정답은 아니다.
- 실제 연결 데이터 미확보. 공개 표 접근과 산업 지표 검증, 합성 메커니즘/복원 실험, 실제 고객 예측 성능을 분리한다. 현재 실제·합성 모델 실험 결과는 없다.
- 11/2 규정 재확인은 웹 본문 추출 실패 및 브라우저 URL 판별 실패로 제한됨. 10/30 공식 화면 보존 기록을 근거로 쓰며 AI 도구 상세 규정은 여전히 미확인.

### Claude 독립 검토 요청

1. 채찍 효과를 출제 의도 또는 실제 고객 현상으로 단정한 문장이 있는가?
2. 실제 소비 C와 미충족 수요 C*, 생산 P·주문 O·출하 S·입고 R가 구분되는가?
3. O+I의 비식별 반례와 수급식의 경계·부호·A 귀속 조건이 타당한가?
4. 공개 완제품 통계를 소재 정답으로 오인하거나 합성 생성식 역산을 일반 성능으로 과장하지 않았는가?
5. 사후 복원과 실시간 예측 입력의 정보 시점, 동일 목표에 대한 비교가 적절한가?
6. 소비 복원 연구가 공식 미래 FCST·현업 의사결정과 충분히 연결되는가?

### Orchestrator·사용자 미결정

- V1의 복원 대상 C 정의, 자동차용 PC/ABS와 한 경로를 채택할지.
- 내부 최소 데이터가 없을 때 합성 메커니즘 시연만으로 진행할지. 실측 복원 정확도는 포기한다는 한계의 수용 여부.
- 합성 주기·기간, 최소 추정 방법·미래 예측 방법, LLM/에이전트 동작 수준. 구현 여부는 이후 결정.
- AI 도구 세부 규정·지원서 현행 제한을 제출 전에 어떻게 최종 확인할지. 이번에 외부 문의는 보내지 않음.
- 남은 일정 재배치와 필수 답변/설명 자료 우선순위. 실제 성능 주장 없이 제출 가능한 수준을 우선할지.

이 갱신은 사용자 지시와 조사 결과를 기록하며, Claude 독립 승인이나 orchestrator의 소재·구현 채택 결정을 대신하지 않는다.
