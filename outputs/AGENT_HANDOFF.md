# 웹GPT · Codex · Claude 협업 안내

## 공통 배경

롯데 AX Challenge 2026의 롯데케미칼 첨단소재 수요예측 AI 기획 과제를 준비한다. 마감은 2026-11-04 23:59 KST. 사용자는 환경 컨설팅 인턴 중 롯데케미칼 공장 인허가 관련 업무를 접했으며, 고객 데이터와 수요예측 실무 경험은 없고 AI 도움으로 코딩한다.

필수 제출: 정의·기획안 / 구축방안 / AI 역량 각 최대 3,000자. 포트폴리오는 필수 표시가 없으며 100MB 이하. 본선에는 구체화된 과제와 현장 데이터가 제공된다고 안내되어 있다.

실제 거래 고객·예측 성능·사업 효과를 임의로 단정하지 않는다. 출처, 가정, 실제 측정 결과를 구분한다. 제출·계정 조작은 작업 범위에 포함하지 않는다.

## 웹GPT에 전달할 초기 요청

당신은 이 프로젝트의 orchestrator다. Codex는 primary executor, Claude는 independent reviewer다. 첨부한 PROJECT_PLAN.md를 기준으로 우선순위와 단계별 작업을 조율해 달라. 첫 단계는 소재·산업 선택과 예측 대상 정의다. PC/ABS 자동차용과 ABS 가전용은 후보이며 아직 확정하지 않았다. 예선 필수 답변과 이해 가능한 작은 시연을 우선하고 범위를 확대하지 말아 달라. 각 작업 지시에는 목표, 입력 자료, 산출물, 완료 기준을 포함해 달라. 리뷰 의견이 충돌하면 쟁점과 판단 근거를 정리해 달라.

## Codex 작업 지시 형식

- 작업 ID / 목표
- 입력 자료와 확정된 결정
- 작업 범위와 이번에 제외할 기능
- 필요한 산출물
- 완료 기준
- Claude가 확인할 핵심 쟁점

## Claude에 전달할 검토 요청

당신은 독립 검토자다. 실행자의 결론을 그대로 받아들이지 말고, 공식 과제 요구사항과 첨부 결과물을 기준으로 검토해 달라. 특히 (1) End Customer 정의, (2) 소재 소비량과 주문량의 구분, (3) 공개 지표를 고객사 수요로 연결하는 가정, (4) 합성 데이터 성능의 과장, (5) 시간 순서와 데이터 누수, (6) AI 에이전트 역할의 실체, (7) 사용자의 실제 경험·기여 표현을 확인해 달라. 불확실한 내용은 사실 오류와 구분해 질문으로 남겨 달라.

의견마다 다음을 제시해 달라:
- 중요도: 제출 전 필수 수정 / 개선 권고 / 질문
- 대상 문장·파일·위치
- 문제와 근거
- 가능한 최소 수정

검토 결과는 work/reviews/에 보관하고, Codex는 의견별 수용·부분 수용·보류와 이유 및 수정 내용을 기록한다. 해결되지 않은 방향 결정은 웹GPT와 사용자에게 전달한다.

## 결과 전달 패킷

1. 이번 작업의 결과
2. 생성·변경한 파일
3. 사용한 출처와 데이터
4. 사실 / 가정 / 미확인 사항
5. 실행·검증 결과
6. 다음 단계에 필요한 결정

현재 상태: 계획과 폴더만 생성. 외부 도구 자동 연결, Claude 검토, 모델 구현은 아직 수행하지 않았다.
