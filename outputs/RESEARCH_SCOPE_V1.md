# 연구 범위 V1 — 주문 신호 왜곡과 소재 소비량 복원

> **V1 완료 산출물/합성 실험 기준.** 2026-11-03부터 외부 산업지표를 조금씩 추가하는 **V2 확장 방향(연구·데이터 수집 단계)**은 [PROJECT_SYNC_2026-11-03.md](PROJECT_SYNC_2026-11-03.md)를 우선 참조한다. 이 V1 문서는 기존 모델·검증의 역사적 범위이며 V2 구현 완료를 의미하지 않는다.

2026-11-02 KST · **현행 연구 방향 / Round 03 반영**. 합성 최소 실험 실행 완료, 실제 고객 검증 미수행.

**연구 질문:** 주문 신호 왜곡을 고려한 End Customer **미래 FCST**를 설계한다. 소비 복원은 내부의 한 단계다. 재고 조정·묶음 발주·리드타임이 섞인 주문에서 소비를 어느 조건에서 추정할 수 있고 다음 1개월 예측에 도움이 되는가? 채찍 효과는 가설이며 출제 의도가 아니다.

**추천:** 자동차용 PC/ABS, 가상 완성차사 A–가상 부품 성형업체 B 한 경로·소재군 하나. [공식 모빌리티 제품](https://product.lottechem.com/ko/advanced_materials/mobil_pc_alloy1.do)과 회사 단위 월간 판매 표 접근이 근거다. 가전용 ABS는 [냉장고 내상 적용](https://product.lottechem.com/ko/advanced_materials/abs.do)이 구체적이고 일본 월간 생산·출하·재고 통계 경로가 있으나, 완제품 재고여서 수지 복원 정답이 아니다. 양 후보 모두 소재 주문–입고–재고–소비의 연결 실측자료는 미확보. 자동차의 복원 성능 우위가 아니라 기존 조사 재사용·범위 유지에 따른 추천이다.

| 정의 | 이번 범위 |
|---|---|
| 최종 소비자 | 자동차 구매·사용자. 소재를 직접 발주하는 주체와 다름 |
| End Customer | 완제품 제조사 A로 작업상 정의. 주최 측 내부 용어의 범위는 미확인 |
| 직접 주문 고객 | A 관련 부품을 생산하는 성형업체 B로 가정. 가공업체·부품업체는 같은 법인일 수 있음 |
| 복원 대상 C | B가 A용 부품 생산에 실제 투입한 PC/ABS, 톤/월. 모든 공급사 물량 기준. 품절로 실현되지 않은 희망 수요와 구분 |
| 미래 대상 | 1차: 다음 1개월 C 예측과 조건부 불확실성. 2차: 공급비중·재고정책을 가정한 롯데 주문 시나리오(주문 정확도 평가 아님) |

**관측 조건:** 주문 O만 있으면 C는 일반적으로 유일하게 식별되지 않는다. O와 재고 I만 있어도 실제 입고 R·취소·미입고가 빠지면 동일하다. 같은 경계의 I·R·반품/이동·손실을 알면 수급식으로 실제 소비를 계산할 수 있다. 제품 생산량 P가 추가돼도 부품 구성·원단위·소재 선택·생산 시차 없이는 실제 톤을 확정할 수 없다. 산업 전체 지표에서 A로 연결하려면 거점·차종별 생산비중과 A–B 납품 매핑이 추가로 필요하다.

O/R/I는 B 전체 공급사 경계의 자료다. 롯데 관점의 관측 후보는 **자사 O_LC/S_LC와 이용 시점이 확인된 고객 보고·생산 대리지표**이며 실제 고객 자료 확보를 뜻하지 않는다. 자사 주문만으로 단기 소비는 식별 불가. 전체 O의 장기 평균은 I/W 유계·기타 유출입 평균 보정 조건에서 C 평균에 접근할 수 있다. 최소 모형은 숨은 C의 랜덤워크와 자사 주문/공급비중·지연된 대리지표 관측식이다. 전체 입고 없는 재고 보고는 업데이트에 사용하지 않는다.

**사용자·의사결정:** 영업·수요계획 담당자가 ‘주문 급변이 소비 변화인가, 재고·발주 변화인가’를 검토하고 고객 확인 우선순위와 생산·재고 검토의 근거로 사용한다. 자동 발주·생산 의사결정은 범위 밖이다.

**검증:** 합성 48개월×20시드, 마지막 12개월의 1개월 앞 C에 대해 주문 3개월 평균 / 관측 직접 활용 / 상태 추정 추가를 비교했다. 기본 조건 MAE는 49.872 / 32.495 / 28.282톤, 대리지표 오염 시 49.872 / 42.127 / 47.447톤(공급비중 가정 .45). 추정이 항상 개선되지 않았다. 명목 95% 상태 예측 구간 포함률도 기본 45.0%로 불충분해 확률 보증이 아니다. 공급비중 .30/.45/.60 민감도, 시점 누수·식별 불가·수급 검사와 재현성도 확인. 실측 고객 성능·효과는 입증하지 않았다.
