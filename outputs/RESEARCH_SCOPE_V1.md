# 연구 범위 V1 — 주문 신호 왜곡과 소재 소비량 복원

2026-11-02 KST · 조사·설계 결과 / 구현 미착수

**연구 질문:** 재고 조정·묶음 발주·리드타임이 섞인 주문에서 End Customer에 귀속되는 소재 소비를 어느 조건에서 추정할 수 있으며, 그 추정이 다음 1~3개월 소비 예측에 도움이 되는가? 채찍 효과는 연구 가설이며 롯데의 출제 의도로 단정하지 않는다.

**추천:** 자동차용 PC/ABS, 가상 완성차사 A–가상 부품 성형업체 B 한 경로·소재군 하나. [공식 모빌리티 제품](https://product.lottechem.com/ko/advanced_materials/mobil_pc_alloy1.do)과 회사 단위 월간 판매 표 접근이 근거다. 가전용 ABS는 [냉장고 내상 적용](https://product.lottechem.com/ko/advanced_materials/abs.do)이 구체적이고 일본 월간 생산·출하·재고 통계 경로가 있으나, 완제품 재고여서 수지 복원 정답이 아니다. 양 후보 모두 소재 주문–입고–재고–소비의 연결 실측자료는 미확보. 자동차의 복원 성능 우위가 아니라 기존 조사 재사용·범위 유지에 따른 추천이다.

| 정의 | 이번 범위 |
|---|---|
| 최종 소비자 | 자동차 구매·사용자. 소재를 직접 발주하는 주체와 다름 |
| End Customer | 완제품 제조사 A로 작업상 정의. 주최 측 내부 용어의 범위는 미확인 |
| 직접 주문 고객 | A 관련 부품을 생산하는 성형업체 B로 가정. 가공업체·부품업체는 같은 법인일 수 있음 |
| 복원 대상 C | B가 A용 부품 생산에 실제 투입한 PC/ABS, 톤/월. 모든 공급사 물량 기준. 품절로 실현되지 않은 희망 수요와 구분 |
| 미래 대상 | 월말 기준 C의 다음 1~3개월 전망. 롯데 주문 전망은 공급비중·재고정책·리드타임을 거쳐 별도 산출하는 후속 사용처 |

**관측 조건:** 주문 O만 있으면 C는 일반적으로 유일하게 식별되지 않는다. O와 재고 I만 있어도 실제 입고 R·취소·미입고가 빠지면 동일하다. 같은 경계의 I·R·반품/이동·손실을 알면 수급식으로 실제 소비를 계산할 수 있다. 제품 생산량 P가 추가돼도 부품 구성·원단위·소재 선택·생산 시차 없이는 실제 톤을 확정할 수 없다. 산업 전체 지표에서 A로 연결하려면 거점·차종별 생산비중과 A–B 납품 매핑이 추가로 필요하다.

**사용자·의사결정:** 영업·수요계획 담당자가 ‘주문 급변이 소비 변화인가, 재고·발주 변화인가’를 검토하고 고객 확인 우선순위와 생산·재고 검토의 근거로 사용한다. 자동 발주·생산 의사결정은 범위 밖이다.

**검증:** 공개 실측은 지표 접근·단위·판본·공표 시점 확인까지만 현재 가능하다. 실제 고객 채찍 효과·소비 복원 정확도·예측 개선은 입증 불가. 후속 합성 시연에서는 알려진 C에서 발주·재고·입고를 생성해 관측 조건별 복원 오차와 식별 실패를 확인한다. 별도로 같은 미래 C를 대상으로 주문 기반 예측과 복원값 기반 예측을 시간 순서로 비교한다. 미래 자료를 쓰는 사후 복원은 실시간 예측 입력에서 제외한다. 합성 결과는 설정한 메커니즘의 작동 원리만 검증한다.

**다음 결정:** 소비 복원 범위 채택 → Claude 독립 검토 → 구현 여부·최소 방법 선택. 이번 단계에서는 데이터 생성·모델·앱 구현 및 지원서 최종 작성 없음. 과제 연결을 위해 복원 자체보다 ‘조건부 추정→미래 FCST→담당자 확인’ 흐름을 유지한다.
