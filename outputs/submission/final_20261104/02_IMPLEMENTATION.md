구축 흐름은 입력 점검→시점 확인→잠재 소비 추정→다음 1개월 예측→불확실성 보고→담당자 확인입니다. 가상 A–B 경로의 월간 자료를 사용하며 고객 전체 주문 O·입고 R·재고 I와 롯데 자사 주문 O_LC·출하 S_LC를 분리합니다. 실환경에서는 실제 공유 권한과 제공 주기를 확인한 자료만 사용합니다.

최소 추정 방법은 소비 C를 숨은 상태로 둔 칼만 필터입니다. 소비는 전월 수준에서 잡음과 함께 변한다고 가정합니다. 자사 주문은 가정한 공급비중으로 환산하되 재고·발주 왜곡 때문에 관측 잡음을 크게 둡니다. 생산 대리지표는 원단위 가정으로 소비 대응량을 만들고, 발표·보고 시점 이후에만 사용합니다. 이는 산업 전체 생산량을 고객 실제 소비로 간주하는 것이 아닙니다.

간헐적인 재고만으로는 소비를 직접 측정할 수 없습니다. 동일 경계의 전체 입고·재고·반품/이동·손실이 함께 맞아야 수급식으로 소비를 계산할 수 있습니다. 최소 모형에서는 입고가 빠진 재고 보고를 필터 관측으로 넣지 않고 확인 요청에 사용합니다. 대리지표가 없고 주문 정책·공급비중도 불확실하면 식별 불가를 표시합니다. 모형이 내는 구간도 가정에 조건부인 값이며 실제 정확도를 보증하지 않습니다.

검증은 합성 월간 48개월·20개 시드에서 마지막 12개월의 다음 달 C를 대상으로 실행했습니다. 최근 3개월 자사 주문 평균, 이용 가능한 주문·대리지표의 직접 활용, 같은 정보에서 상태 추정값을 추가하는 예측을 비교했습니다. 공급비중 45% 가정의 기본 조건 MAE는 각각 49.872·32.495·28.282톤이었습니다. 대리지표를 50% 높인 오염 조건에서는 49.872·42.127·47.447톤으로, 상태 추정 추가가 직접 활용보다 나빠졌습니다. 이는 합성 가정하의 결과이며 실제 고객 성능이 아닙니다.

다만 2개월 묶음발주 조건에서 최근 3개월 주문 평균은 주기가 맞지 않아 불리할 수 있습니다. 기본 조건의 공급비중 45%와 원단위 2kg/대는 생성기의 참값과 같고, 생산 대리지표도 실제 소비에 가깝게 연결한 유리한 합성 구조입니다. 결과에는 기준 창 선택과 관측 가중·최신성의 영향이 있어 칼만 필터가 독보적으로 우수하다고 결론 내리지 않습니다.

공급비중 30%·45%·60% 민감도와 편향도 출력했습니다. 상태 단독 예측의 명목 95% 구간 포함률은 기본 조건에서도 45%에 그쳐 실무 확률 보증으로 쓰지 않습니다. 참 소비는 합성 생성·평가에만 사용하며 필터·예측 입력과 파라미터 조정에는 사용하지 않았습니다. 미래·미입수 관측 변경에 대한 불변성, 수급식·단위·중복, 불완전 재고 비사용, 주문만 있을 때의 식별 불가 처리를 포함한 7개 검증을 통과했습니다.

AI 에이전트 개발방식은 현재 구현과 향후 설계를 구분합니다. 현재는 Python 표준 라이브러리 기반 규칙형 CLI가 입력·시점 점검, 상태 추정·예측 호출, 이상·불확실성 보고와 담당자 확인 요청을 순서대로 연결합니다. 칼만 필터는 수치 추정 모형이며 LLM이나 자율 에이전트가 아닙니다.

향후에는 데이터 검증·예측 실행·근거 설명·담당자 검토 요청을 각각 도구로 구성한 워크플로를 설계합니다. 자료 도착 시 검증·예측 도구를 실행하고, 식별 불가나 이상 신호가 있으면 관측 근거와 가정을 정리해 담당자에게 확인을 요청하도록 합니다. 수치 계산은 모델이 수행하고 설명 단계가 임의로 변경하지 않으며 생산·발주 결정은 사람의 확인을 거치도록 합니다. 이 도구 기반 워크플로의 에이전트화와 외부 LLM 연동, 자율 에이전트, 현업 배포는 미구현이며 실제 고객 성능 검증도 수행하지 않았습니다.

실제 공개 산업지표를 활용하는 탐색적 확장 실험도 수행했습니다. KOSIS 생산 원지수 C222(플라스틱 제품)·C303(자동차 부품)와 한국은행 신규수주 전망 BSI를 출처·코드·월·원본 해시를 확인해 결합하고, 2025-10~2026-09의 12개월을 t−2 학습 마감으로 평가했습니다. C222에서 BSI 단변량 회귀는 과거 평균보다 MAE가 23.32% 악화했지만, 최근 6개월 YoY 평균은 7.5501→5.8097p.p.로 23.05% 개선됐습니다. 반면 C303에서는 최근 평균과 BSI가 단순 기준선보다 낫지 않았습니다. 이는 최신 수정 판본을 활용한 사후 탐색으로, 당시 이용 가능한 판본의 엄격한 백테스트나 고객별 PC/ABS 소비톤·롯데 주문량의 예측 성능이 아닙니다. 성능을 본 뒤 추가로 모델을 튜닝하는 대신 2026-10·11월 대상의 기존 예측 12개와 별도 최근 평균 예측 8개를 각각 SHA-256으로 봉인했습니다. 목표월 공식 실적에 대한 채점은 하지 않았습니다. 향후 출처·공표일·이용 가능 시점·판본을 분리 관리하고 담당자가 자료와 가정을 확인하는 워크플로를 설계할 수 있으나, 자율 에이전트·현업 배포·실제 고객 수요 예측 성능 검증은 미구현입니다.
