# 범위 제안 — 자동차용 PC/ABS 우선

2026-10-30 KST · 조사 결과에 따른 **추천안**, 최종 결정 전 · 마감 11/4 23:59

**추천:** 가상 완성차사 A의 수요 신호를 가상 직접 주문처 B의 PC/ABS 소비·주문으로 연결하는 월간 FCST 체계. 소재군 하나, End Customer 하나, 주문 경로 하나로 제한한다. 내장 전용 등급·실제 거래처는 확정하지 않는다.

| 비교 | 자동차용 PC/ABS | 가전용 ABS — 냉장고 내상 |
|---|---|---|
| 제품 근거 | [롯데 모빌리티 PC Alloy](https://product.lottechem.com/ko/advanced_materials/mobil_pc_alloy1.do)에 PC/ABS | [압출 ABS](https://product.lottechem.com/ko/advanced_materials/abs.do), [HIPS 대체 가능성](https://product.lottechem.com/ko/tech/case_study/7/view.do?page=8) 확인 |
| 실제 공개 수치 확보 | 현대차 공식 월별 판매 표 2025년 10~12월, 3개 고유월·판본별 4행 수동 전사 | 중국 NBS 냉장고 2025 연간 생산 1개 값 전사. 일본 2024 월별 표는 항목·경로만 확인 |
| 남는 간극 | 판매≠생산. 차종·부품·거점·원단위·공급비중·재고 필요 | 국가 집계→개별 회사 배분, ABS/HIPS 선택·원단위·공급비중 필요 |

자동차는 회사 단위 월별 공개 표를 계정 없이 읽을 수 있어 End Customer 관점을 설명하기 쉽다. 짧은 일정과 사용자의 경험 수준을 고려해 다국가 통계 처리보다 단일 경로의 가정·검증을 설명하는 데 집중한다. **장기 학습자료 확보나 자동차 예측 성능 우위를 뜻하지 않는다.** 두 후보 모두 실제 고객 정답은 없다. 근거·상태: [SOURCE_LOG](../work/research/SOURCE_LOG.md), [소량 전사 표](../work/research/PUBLIC_DATA_SAMPLE.md).

| 구분 | 이번 제안의 정의·대상 |
|---|---|
| End Customer | 가상 완성차 제조사 A. 최종 소비자인 개인 구매자와 구분. 주최 측 내부 정의는 미확인 |
| 직접 주문 고객 | A 관련 부품을 만드는 가상 성형업체 B. 롯데에 발주하는 주체로 가정; A와 같을 수도 있음 |
| 소재 소비량 | A 제품에 연결된 B의 PC/ABS 투입량, 톤/월. 전체 공급사 소비와 롯데 공급분 구분 |
| 자사 주문량 | B가 롯데에 발주한 PC/ABS 주문 중 A에 귀속되는 양, 톤/월. 소비·출하·매출과 구분 |

**예측·사용자:** 월말에 다음 1~3개월의 `A×B×PC/ABS 소재군×요청납기월` 주문량을 예측한다. 확정 수주와 아직 주문되지 않은 예상분을 구분한다. 영업·수요계획 담당자가 고객 확인 우선순위와 월간 생산·재고 검토에 사용하며 자동 발주·생산 지시는 하지 않는다.

**연결 전제:** 공개 판매는 보조 신호다. 고객 생산계획→차종/부품별 투입량→수율을 반영한 소재 소요→재고·미입고·다른 공급사·롯데 배분·리드타임→주문으로 연결한다. 고객/부품 매핑, BOM, 공급 점유율, 주문·재고 이력은 미확보이므로 시연에서는 명시적 가정이다. 국가 산업 지표를 고객 비중 없이 배분하거나 대수를 바로 톤으로 바꾸지 않는다.

**작은 시연 설계:** 실제 공개 표는 출처·단위·공표일 확인용으로만 사용. 별도 표시한 합성 36개월의 A 생산계획·B 주문/재고·가정 원단위를 입력해 소비→주문 연결, 다음 1~3개월 표, 가정 변경 시나리오와 담당자 확인 사유를 출력한다. 공개 표와 가상 고객의 실제 관계를 만들지 않는다. 기준은 최근 3개월 평균; 비교 방법 하나는 다음 단계에서 선택. 6개 월말 시점의 순차 검증, MAE/WAPE·편향, 공표일 누수·0주문·단위·중복 검사로 동작을 확인한다. **합성 오차는 실제 고객 성능의 증거가 아니다.**
