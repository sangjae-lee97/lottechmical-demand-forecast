## 2. 출발점과 범위

사용자는 환경 컨설팅 인턴 중 롯데케미칼 공장 인허가 관련 업무를 접하며 공장 구성과 공정 이해의 출발점을 얻었다. 고객사·수요예측 실무 경험과 자체 고객 데이터는 없고, 코딩에는 AI 도움이 필요하다.

인턴 경험은 산업 관심과 문제 접근의 배경으로 활용한다. 경험하지 않은 설계·운영 업무를 수행했다고 쓰지 않는다. 과거 업무의 비공개 자료는 사용하지 않고 공개 자료와 명시적인 가정으로 준비한다.

시범 범위 후보: 자동차 내장재용 PC/ABS 또는 가전용 ABS 중 하나. 소재·산업의 공개 자료 확보 가능성을 비교한 뒤 선택한다. 고객사는 A/B/C 등 가상 고객으로 두고, 월 단위 예측을 우선 검토한다. 이 선택은 실제 롯데케미칼 고객 관계를 뜻하지 않는다.

첫 조사에서 확정할 질문:
1. End Customer가 최종제품 제조사인지, 직접 주문 고객인지, 양자를 어떻게 연결할지.
2. 예측 대상이 고객의 소재 소비량인지, 롯데케미칼에 대한 주문량인지.
3. 고객×소재군 수준에서 다음 몇 개월을 예측할지, 누가 어떤 결정을 내릴지.
4. 필요한 내부 데이터와 공개 대체 지표는 무엇인지.

## 3. 역할과 작업 흐름

| 역할 | 담당 | 책임 |
|---|---|---|
| 최종 판단·제출 | 사용자 | 방향 선택, 실제 경험 확인, 제출 내용 승인 및 제출 |
| Orchestrator | 웹GPT | 전체 방향·우선순위·작업 지시·상충 의견 조정 |
| Primary executor | Codex | 근거 조사, 데이터 처리, 구현, 검증, 지원서·포트폴리오 초안 |
| Independent reviewer | Claude agent | 과제 적합성, 가정, 데이터 누수, 검증, 과장·누락을 독립 검토 |

흐름: 웹GPT 작업 지시 → Codex 결과와 근거·미해결점 작성 → Claude 독립 검토 → Codex 수정 및 의견별 답변 → 필요 시 웹GPT가 쟁점 결정 → 사용자 최종 확인.

웹GPT와 Claude의 연결·자동 호출은 설정하지 않았다. 현재는 사용자가 작업 패킷을 각 도구에 전달하는 방식으로 계획한다. 별도 에이전트는 생성하지 않는다. 검토에는 사실과 가정이 구분된 결과물 및 평가 기준을 전달한다.

## 5. 최소 시연과 검증

최소 시연:
- CSV 입력: 가상 고객·소재·월별 주문량. 필요하면 재고·외부 신호를 추가.
- 단순 기준모델 하나와 비교 모델 하나의 예측 결과 표시.
- 고객별 월간 예측, 오차, 급변 알림을 한 화면 또는 보고서로 표시.
- 에이전트가 할 일과 계산 모델이 할 일을 분리. 모델이 수치를 계산하고 에이전트가 데이터 점검·예측 실행·근거 설명·담당자 확인 요청을 연결.
- LLM 연동이 없다면 규칙 기반 시연이라고 표시하고, LLM 에이전트는 설계 수준임을 명시.

검증 원칙:
- 과거로 학습하고 이후 기간으로 평가한다. 평가 시점에 알 수 없던 데이터는 입력하지 않는다.
- 합성 데이터는 가정과 생성 과정을 공개하고 실제 고객 성능의 근거로 쓰지 않는다.
- 공개 산업 지표의 예측과 고객사 주문 예측을 동일시하지 않는다.
- 효과 수치는 실제 실적이 아니라 목표 또는 조건부 시나리오로 표시한다.
- 공개 자료 확보에 시간이 걸리면 장시간 수집을 중단하고 설계·합성 시연의 완성도를 우선한다.

## 6. 산출물과 완료 기준

최종 산출물:
1. 지원서 필수 답변 3개 — 각 최대 3,000자, 입력 화면에서 최종 확인.
2. 짧은 포트폴리오 — 문제·설계·시연·검증·한계·본인 기여.
3. 재현 가능한 시연과 실행 안내 — 작업 파일로 유지, 요청 형식에 맞춰 첨부 여부 결정.
4. 출처 목록, 검토 의견 및 처리 기록.

사용자가 설명할 수 있어야 할 내용:
- 누구의 무엇을 예측하며 어떤 의사결정에 쓰는가.
- 실제 데이터와 합성 데이터는 각각 무엇인가.
- 모델과 AI 에이전트는 각각 무엇을 담당하는가.
- 어떤 비교와 검증을 했으며 무엇은 아직 입증하지 못했는가.
- 사용자가 결정·검증한 부분과 AI의 도움을 받은 부분은 무엇인가.

완료 조건: 필수 답변의 근거·일관성·글자 수 확인, 시연 재실행 확인, Claude 주요 지적 처리 또는 미해결 이유 기록, 사용자 사실 확인. 독립 검토가 아직 실행되지 않았다면 완료했다고 표시하지 않는다.
