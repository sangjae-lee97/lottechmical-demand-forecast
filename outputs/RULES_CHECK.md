## 3. 명확히 남는 미확인

- ChatGPT·Claude·Codex 등 생성형 AI/코딩 도구, 특정 모델·외부 API·외부 통신의 허용 범위와 공개 의무. 공개 FAQ 목록과 공식 도메인 검색에서 명시 규정을 찾지 못했으나 **금지 없음=허용 확인**은 아니다. 다른 대회의 도구 허용 문구를 가져오지 않는다.
- 예선 코드 제출의 필수 여부. 현재 보존된 필드·공고에 필수 코드 요구를 확인하지 못했을 뿐, 면제 확정으로 쓰지 않는다. ZIP 허용도 코드 의무를 뜻하지 않는다.
- 공백/줄바꿈 포함 글자 수 산정, 첨부 개수, 결과물 권리·오픈소스 표기, 본선 데이터 반출·외부 모델 전송 조건, 본선 도구·비용 지원, 배점·평가 정답 데이터.
- 11/2 이후 변경 공지 여부. 제출 전 사용자 로그인 화면/공식 추가 안내로 최종 확인할 필요가 있다. 이번 작업에서 문의 메시지는 보내지 않았다.

## 4. 새 연구 방향과 공식 과제의 관계

공개 과제 문구는 FCST 체계·모델 기획을 요구한다. **채찍 효과, 잠재 수요 복원, 특정 소재/산업/예측 기간을 주최 측 요구로 명시한 기록은 없다.** 따라서 본 연구는 ‘주문 신호 왜곡 가능성을 고려한 고객 소재 소비 추정과 미래 FCST’라는 제안으로 서술한다.

연구가 역문제 분석에서 끝나지 않도록 다음 1~3개월 소비 예측과 영업·수요계획 판단에 연결한다. AI 에이전트는 데이터 충분성 확인·단위/시점 검사·추정/예측 실행 연결·불확실성 및 담당자 확인 요청 역할로 설계할 수 있다. LLM이나 에이전트를 실제 구현했다고 적을 근거는 현재 없다. 구현 수준은 독립 리뷰 후 별도 결정한다.
